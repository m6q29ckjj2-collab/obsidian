# Рынок IT на hh.ru: сколько кандидатов на вакансию

Снято 2026-10-10 с публичных страниц поиска hh.ru (API закрыт). Вся Россия, поиск **по названию** вакансии/должности в резюме.
«Ищущих» = резюме со статусом «активно ищу» или «рассматриваю предложения». Последний столбец = ищущих / вакансий.

## Выводы

- **Самая высокая конкуренция:** фронтенд (около 100 ищущих на вакансию), UX/UI (62), TypeScript (62), Flutter (60), веб-дизайн (131), верстальщик.
- **Средняя:** основной бэкенд — Python 35, C# 39, PHP 36, Go 24, Java 22. Mobile около 30.
- **Дефицитные для кандидатов (мало людей на место):** сетевые инженеры (2), DBA (4), Scala (4), embedded (6), 1С (10), ИБ/SOC (10–11), сисадмины (14), SRE (16), C++ (17), DevOps (20).
- Ищущие составляют лишь 15–25% от всех резюме, поэтому смотреть надо на столбец «ищущих».

## Ограничения

- Вакансий, скорее всего, занижено: искал только по названию. Для Java по всему тексту выходило около 1 320, по названию 411.
- Не прочитались: резюме для React, ETL, LLM; вакансии для Elixir. Нули в «ищущих» у Kotlin Android и DevSecOps, скорее всего, сбой. Эти цифры использовать нельзя.
- Шумные запросы («Безопасность», «Разработчик», «Architect») захватывают не только IT, поэтому в таблицы не включены.
- Один человек может иметь несколько резюме, а у вакансии может быть несколько мест. Соотношение даёт порядок величины, а не точный конкурс.
