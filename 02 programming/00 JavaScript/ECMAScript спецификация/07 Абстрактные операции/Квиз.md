> [!question] На сколько частей разбита глава об абстрактных операциях?
> a) две
> b) три
> c) четыре
> d) шесть
>> [!success]- Answer
>> c) четыре
>> Преобразования типов, сравнения и проверки, операции над объектами, операции над итераторами

> [!question] Что выведет код?
> ```js
> const dual = {
>   [Symbol.toPrimitive](h) {
>     return h === 'number' ? 42 : h === 'string' ? 'строка' : 'умолчание';
>   }
> };
> console.log(+dual, `${dual}`, dual + '');
> ```
> a) `42 строка умолчание`
> b) `42 42 строка`
> c) `умолчание строка 42`
> d) `42 строка строка`
>> [!success]- Answer
>> a) `42 строка умолчание`
>> Унарный плюс просит число, шаблон — строку, бинарное сложение — хинт по умолчанию

> [!question] Какие ровно два места запрашивают хинт по умолчанию?
> a) унарный плюс и шаблонные строки
> b) бинарное сложение и нестрогое равенство
> c) реляционные операторы и приведение ключа
> d) все арифметические операторы
>> [!success]- Answer
>> b) бинарное сложение и нестрогое равенство
>> Всё остальное просит число или строку явно

> [!question] Что выведет код?
> ```js
> const d = new Date(0);
> console.log(typeof (d + 1), typeof (d - 1));
> ```
> a) `string number`
> b) `number number`
> c) `string string`
> d) `object number`
>> [!success]- Answer
>> a) `string number`
>> Дата — единственный встроенный тип, трактующий хинт по умолчанию как строковый

> [!question] Что произойдёт?
> ```js
> const hostile = Object.create(null);
> `${hostile}`;
> ```
> a) вернёт текстовое представление объекта
> b) вернёт пустую строку
> c) выбросит `TypeError`
> d) вернёт `'null'`
>> [!success]- Answer
>> c) выбросит `TypeError`
>> Ни текстового, ни числового метода у такого объекта нет, поэтому привести его к примитиву невозможно

> [!question] Что выведет код?
> ```js
> console.log(Number(''), Number('   '), Number('12px'), Number('0x1F'));
> ```
> a) `0 0 12 31`
> b) `0 0 NaN 31`
> c) `NaN NaN NaN 31`
> d) `0 NaN NaN 0`
>> [!success]- Answer
>> b) `0 0 NaN 31`
>> Требуется, чтобы вся строка была числом. Пробелы по краям отбрасываются, шестнадцатеричная запись понимается

> [!question] Обращается ли приведение к логическому типу к содержимому объекта?
>> [!success]- Answer
>> False
>> Любой объект истинен без вызова его методов. Поэтому истинны и пустой массив, и обёртка над ложным значением

> [!question] Сколько всего ложных значений в языке?
> a) `5`
> b) `6`
> c) `7`
> d) `8`
>> [!success]- Answer
>> d) `8`
>> Ложь, ноль, минус ноль, нулевое значение произвольной точности, пустая строка, неопределённое значение, пустая ссылка и нечисло

> [!question] Что выведет код?
> ```js
> console.log(2 ** 32 | 0, -1 >>> 0, 1.9 | 0, -1.9 | 0);
> ```
> a) `0 4294967295 1 -1`
> b) `4294967296 -1 2 -2`
> c) `0 -1 1 -1`
> d) `0 4294967295 2 -2`
>> [!success]- Answer
>> a) `0 4294967295 1 -1`
>> Побитовые приводят к 32 битам со знаком, беззнаковый сдвиг — без знака. Дробная часть усекается к нулю

> [!question] Что выведет код?
> ```js
> const o = {};
> o[1] = 'a'; o['1'] = 'b'; o[{}] = 'c';
> console.log(Object.keys(o).length, o[1]);
> ```
> a) `3 'a'`
> b) `2 'b'`
> c) `2 'a'`
> d) `3 'b'`
>> [!success]- Answer
>> b) `2 'b'`
>> Ключ приводится к строке, поэтому числовой и строковый совпадают, а любой обычный объект даёт одно и то же имя

> [!question] Что вернёт код?
> ```js
> console.log(Array.prototype.slice.call({ length: -5 }).length);
> ```
> a) `-5`
> b) `0`
> c) `5`
> d) выбросит `RangeError`
>> [!success]- Answer
>> b) `0`
>> Приведение длины ограничивает значение диапазоном от нуля до максимального безопасного целого

> [!question] Что выведет код?
> ```js
> console.log(NaN === NaN, Object.is(NaN, NaN), [NaN].includes(NaN), [NaN].indexOf(NaN));
> ```
> a) `false true true -1`
> b) `true true true 0`
> c) `false false true -1`
> d) `false true false -1`
>> [!success]- Answer
>> a) `false true true -1`
>> Три алгоритма равенства расходятся именно здесь: поиск по совпадению использует один, поиск по индексу — другой

> [!question] Что выведет код?
> ```js
> console.log(Object.is(0, -0), [0].includes(-0), 0 === -0);
> ```
> a) `true true true`
> b) `false true true`
> c) `false false true`
> d) `true false false`
>> [!success]- Answer
>> b) `false true true`
>> Только сравнение значений различает знак нуля. На нечисле расхождение обратное

> [!question] Что выведет код?
> ```js
> console.log(null == 0, null >= 0, null > 0);
> ```
> a) `false true false`
> b) `true true true`
> c) `false false false`
> d) `false true true`
>> [!success]- Answer
>> a) `false true false`
>> Равенство и сравнение — разные алгоритмы. В равенстве шага приведения к числу нет, в сравнении он обязателен

> [!question] Транзитивно ли нестрогое равенство?
>> [!success]- Answer
>> False
>> Пустая строка равна нулю и строка с нулём равна нулю, но между собой они не равны: при совпадении типов приведения не происходит

> [!question] Что выведет код?
> ```js
> const p = Object.preventExtensions({ a: 1 });
> delete p.a;
> const s = Object.seal({ a: 1 });
> s.a = 99;
> console.log(Object.hasOwn(p, 'a'), s.a);
> ```
> a) `true 1`
> b) `false 99`
> c) `true 99`
> d) `false 1`
>> [!success]- Answer
>> b) `false 99`
>> Запрет расширения касается только добавления, запечатывание разрешает изменение существующих свойств

> [!question] Что выведет код?
> ```js
> let calls = 0;
> const src = { a: 1, get b() { calls++; return 2; } };
> const { ...copy } = src;
> console.log(calls, typeof Object.getOwnPropertyDescriptor(copy, 'b').get);
> ```
> a) `0 function`
> b) `1 undefined`
> c) `1 function`
> d) `0 undefined`
>> [!success]- Answer
>> b) `1 undefined`
>> Копирование данных вызывает аксессор и кладёт в результат вычисленное значение. Ленивость теряется

> [!question] В каком порядке выведутся строки?
> ```js
> function* r() {
>   try { yield 'первый'; yield 'второй'; }
>   finally { console.log('освобождено'); }
> }
> for (const v of r()) { console.log(v); break; }
> ```
> a) `первый` затем `освобождено`
> b) `освобождено` затем `первый`
> c) только `первый`
> d) только `освобождено`
>> [!success]- Answer
>> a) `первый` затем `освобождено`
>> Прерывание перебора вызывает закрытие итератора, что запускает блок финализации генератора
