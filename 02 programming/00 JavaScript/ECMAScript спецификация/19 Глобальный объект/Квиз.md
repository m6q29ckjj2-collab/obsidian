> [!question] Каковы атрибуты свойства `undefined` глобального объекта?
> a) все три истинны
> b) все три ложны
> c) writable истинно, остальные ложны
> d) enumerable истинно, остальные ложны
>> [!success]- Answer
>> b) все три ложны
>> NaN, Infinity и undefined неперечисляемы, неизменяемы и неконфигурируемы — в отличие от большинства других глобальных свойств

> [!question] Что использовалось для ссылки на глобальный объект в разных средах до появления globalThis?
> a) везде было одинаково, стандарт просто зафиксировал существующее имя
> b) в каждой среде свой способ: window, self, global
> c) globalThis существовал с самого начала языка
> d) ссылка на глобальный объект была невозможна
>> [!success]- Answer
>> b) в каждой среде свой способ: window, self, global
>> globalThis стал первой стандартизированной ссылкой, работающей одинаково везде

> [!question] Что выведет код?
> ```js
> function test() {
>   const local = 'локальная';
>   eval('console.log(local)');
>   const indirectEval = eval;
>   try { indirectEval('console.log(local)'); }
>   catch (e) { console.log(e.constructor.name); }
> }
> test();
> ```
> a) `локальная` дважды
> b) `локальная`, затем `ReferenceError`
> c) `ReferenceError`, затем `локальная`
> d) `ReferenceError` дважды
>> [!success]- Answer
>> b) `локальная`, затем `ReferenceError`
>> Прямой вызов eval видит локальную область вызывающего кода, косвенный всегда работает в глобальной

> [!question] Как определяется различие прямого и косвенного вызова eval?
> a) по значению, которое возвращает функция
> b) синтаксически — по форме самого вызова
> c) по режиму строгости
> d) различия не существует
>> [!success]- Answer
>> b) синтаксически — по форме самого вызова
>> Буквальный вызов идентификатора eval(...) считается прямым, любая форма через переменную — косвенным

> [!question] Что выведет код?
> ```js
> console.log(parseInt('0x1F'), parseInt('08'));
> ```
> a) `31 8`
> b) `NaN NaN`
> c) `0 8`
> d) `31 0`
>> [!success]- Answer
>> a) `31 8`
>> Префикс 0x автоматически распознаётся как шестнадцатеричная запись; восьмеричная автоопределяемость из современной спецификации убрана

> [!question] Приводят ли глобальные функции isNaN и isFinite аргумент к числу перед проверкой?
>> [!success]- Answer
>> True
>> В отличие от Number.isNaN и Number.isFinite, которые проверяют значение без приведения

> [!question] Что выведет код?
> ```js
> console.log(encodeURI('a/b?c'), encodeURIComponent('a/b?c'));
> ```
> a) одинаковые результаты
> b) первый оставит /, ?, второй закодирует их
> c) первый закодирует всё, второй ничего
> d) оба бросят исключение
>> [!success]- Answer
>> b) первый оставит /, ?, второй закодирует их
>> encodeURI предполагает целый URI и не трогает разделители компонентов, encodeURIComponent кодирует всё содержимое одного компонента

> [!question] Что произойдёт при попытке закодировать непарный суррогат через encodeURIComponent?
> a) вернёт строку с заменяющим символом
> b) выбросит исключение
> c) вернёт исходную строку без изменений
> d) вернёт пустую строку
>> [!success]- Answer
>> b) выбросит исключение
>> Строка обязана быть корректно оформленным UTF-16 для кодирования в последовательность байтов

> [!question] Конфигурируемо ли глобальное свойство Array?
>> [!success]- Answer
>> True
>> В отличие от NaN, Infinity и undefined, большинство конструкторов из глобального объекта можно удалить или переопределить

> [!question] Что произойдёт после этого кода?
> ```js
> delete globalThis.Array;
> console.log(typeof Array);
> ```
> a) `'function'`, удаление не сработает
> b) `'undefined'`
> c) выбросит `TypeError`
> d) выбросит `SyntaxError`
>> [!success]- Answer
>> b) `'undefined'`
>> Array конфигурируемо, поэтому удаление проходит успешно, и дальнейшие обращения к нему дают неопределённое значение

> [!question] Какие объекты входят в раздел «прочие свойства глобального объекта», не имея собственного конструктора?
> a) Object, Array, Function
> b) Math, JSON, Reflect, Atomics
> c) Error и его подклассы
> d) все типизированные массивы
>> [!success]- Answer
>> b) Math, JSON, Reflect, Atomics
>> Эти объекты нельзя вызвать через new — у них нет соответствующего конструктора

> [!question] Что общего у NaN, Infinity и undefined с точки зрения атрибутов свойств?
> a) они перечисляемы, но неизменяемы
> b) они неперечисляемы, неизменяемы и неконфигурируемы одновременно
> c) они изменяемы, но не удаляемы
> d) их атрибуты зависят от режима строгости
>> [!success]- Answer
>> b) они неперечисляемы, неизменяемы и неконфигурируемы одновременно
>> Это выделяет их среди большинства других глобальных свойств, которые обычно конфигурируемы
