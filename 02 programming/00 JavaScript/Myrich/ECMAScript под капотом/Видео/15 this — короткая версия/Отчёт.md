## Одно правило вместо пяти

Распространённое изложение перечисляет «пять способов вызова» и предлагает их запомнить. Спецификация формулирует короче:

> `this` — не переменная и не параметр. Это результат операции `ResolveThisBinding`, которая через `GetThisEnvironment` находит **ближайшую запись окружения, у которой есть связывание `this`**, и берёт значение оттуда.

Такая запись — **Function Environment Record**, создаваемая при вызове обычной функции. У стрелочных функций она не создаётся, поэтому поиск идёт дальше вверх по `[[OuterEnv]]`.

Всё остальное — следствия.

## Алгоритм в четыре вопроса

```
1. Стрелка?               → this из внешней области, дальше не смотрим
2. Вызов через new?       → новый объект
3. call / apply / bind?   → переданное значение
4. Есть база obj.f()?     → obj
   иначе                  → undefined (strict) / globalThis (sloppy)
```

Побеждает первый подошедший пункт.

## Шпаргалка

```js
function show() { return this; }

show();                     // undefined (strict) · globalThis (sloppy)
show.call('текст');         // 'текст' (strict) · объект String (sloppy)
show.call(null);            // null (strict) · globalThis (sloppy)

const obj = { show };
obj.show();                 // obj — база вызова
(obj.show)();               // obj — скобки ничего не меняют
(0, obj.show)();            // undefined — оператор запятая отбрасывает базу
const f = obj.show; f();    // undefined — база потеряна

new show();                 // новый объект
show.bind(obj)();           // obj
```

Строка с `(0, obj.show)()` — не курьёз: именно так минификаторы и транспиляторы намеренно сбрасывают базу вызова, и это встречается в собранном коде.

## Три состояния связывания

У Function Environment Record есть слот `[[ThisBindingStatus]]`:

| Значение | Когда |
|---|---|
| `lexical` | стрелочная функция — своего `this` нет |
| `uninitialized` | производный конструктор до `super()` |
| `initialized` | обычное состояние |

```js
class Derived extends Base {
  constructor() {
    // this;   // ReferenceError — uninitialized
    super();   // BindThisValue переводит в initialized
    this;      // работает
  }
}
```

## Разница режимов

```js
'use strict';
function strict() { return this; }
strict();               // undefined
strict.call(42);        // 42 — примитив как есть
```

```js
// sloppy
function sloppy() { return this; }
sloppy();               // globalThis — undefined заменяется
sloppy.call(42);        // объект Number — примитив через ToObject
typeof sloppy.call(42); // 'object'
```

Операция `OrdinaryCallBindThis` в нестрогом режиме подменяет `undefined` и `null` глобальным объектом, а примитивы оборачивает. В строгом — передаёт как есть.

> [!note] Классы и модули всегда строгие
> Отдельная директива не нужна: тела классов и код модулей ESM выполняются в строгом режиме по определению. Поэтому оторванный метод класса даёт `undefined`, а не `globalThis`.

## Пять типовых ошибок

```js
// 1. Стрелка как метод объекта — не получит объект
const bad = { value: 1, get: () => this.value };  // undefined

// 2. Обычная функция в коллбэке — потеряет this
class T { start() { setInterval(function () { this.tick(); }, 1000); } }

// 3. Оторванный метод
const m = obj.method;  // база потеряна

// 4. Стрелка обработчиком там, где нужен элемент
el.addEventListener('click', () => this);  // не элемент

// 5. Повторный bind не перезаписывает
f.bind(a).bind(b)();  // this останется a
```

## Итог

> [!success] Что забирать
> - `this` — результат `ResolveThisBinding`, а не переменная; ищется ближайшая Function Environment Record
> - Четыре вопроса по порядку: стрелка → `new` → явное указание → база вызова
> - `(0, obj.f)()` намеренно сбрасывает базу — приём встречается в собранном коде
> - Три состояния `[[ThisBindingStatus]]`: `lexical`, `uninitialized`, `initialized`
> - В sloppy mode `undefined` и `null` заменяются на `globalThis`, примитивы проходят `ToObject`; в strict передаются как есть
> - Классы и модули ESM строгие по определению
> - Стрелка не поддаётся `call`, `apply`, `bind` и `new`; повторный `bind` не перезаписывает связывание
