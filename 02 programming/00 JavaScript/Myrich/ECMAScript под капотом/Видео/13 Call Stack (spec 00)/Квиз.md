> [!question] В каком порядке выведутся значения?
> ```js
> console.log(1);
> setTimeout(() => console.log(5), 0);
> Promise.resolve().then(() => console.log(3)).then(() => console.log(4));
> console.log(2);
> ```
> a) `1 2 3 4 5`
> b) `1 2 5 3 4`
> c) `1 3 4 2 5`
> d) `1 2 3 5 4`
>> [!success]- Answer
>> a) `1 2 3 4 5`
>> Сначала синхронный код, затем очередь микрозадач до полного опустошения, и только потом задача таймера

> [!question] В каком порядке выведутся значения?
> ```js
> Promise.resolve().then(() => console.log('A')).then(() => console.log('C'));
> queueMicrotask(() => console.log('B'));
> ```
> a) `A B C`
> b) `A C B`
> c) `B A C`
> d) `C B A`
>> [!success]- Answer
>> a) `A B C`
>> Второй обработчик регистрируется только после выполнения первого, поэтому попадает в очередь позже явно поставленной микрозадачи

> [!question] Что выведет код?
> ```js

>   console.log('старт');
>   yield 1;
> }

> g.next();
> ```
> a) `старт создан`
> b) `создан старт`
> c) только `создан`
> d) только `старт`
>> [!success]- Answer
>> b) `создан старт`
>> Создание объекта готовит контекст, но не запускает код. Первый шаг доводит выполнение до первой приостановки

> [!question] Что выведет код?

> [!question] Какие из этих вызовов являются хвостовыми?
> ```js
> 'use strict';
> const a = n => n === 0 ? 0 : a(n - 1);
> const b = n => n === 0 ? 0 : 1 + b(n - 1);
> const c = n => { try { return c(n - 1); } catch { return 0; } };
> ```
> a) все три
> b) только первый
> c) первый и третий
> d) ни один
>> [!success]- Answer
>> b) только первый
>> Во втором результат участвует в сложении, в третьем обработчик исключений обязан остаться на стеке

> d) только в модулях
