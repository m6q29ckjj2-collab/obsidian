> [!question] Что выведет код?
> ```js
> const a = [], b = [];
> for (var i = 0; i < 3; i++) a.push(() => i);
> for (let j = 0; j < 3; j++) b.push(() => j);
> console.log(a.map(f => f()), b.map(f => f()));
> ```
> a) `[0,1,2]` и `[0,1,2]`
> b) `[3,3,3]` и `[0,1,2]`
> c) `[0,1,2]` и `[3,3,3]`
> d) `[3,3,3]` и `[3,3,3]`
>> [!success]- Answer
>> b) `[3,3,3]` и `[0,1,2]`
>> У var окружение одно на функцию. Для лексического объявления спецификация создаёт новую запись окружения перед каждой итерацией

> [!question] Что выведет код?

> b) `[30, 30, 30]`
> c) `TypeError`
> d) `[undefined, undefined, undefined]`
>> [!success]- Answer
>> a) `[10, 20, 30]`
>> В этом цикле связывание создаётся заново на каждой итерации по построению, поэтому const допустим и замыкания корректны

> [!question] Что выведет код?
> ```js
> function counter() {
>   let c = 0;
>   return { inc: () => ++c, get: () => c };
> }
> const x = counter();
> x.inc(); x.inc();
> console.log(x.get(), x.c);
> ```
> a) `2 2`
> b) `2 undefined`
> c) `0 undefined`
> d) `2 0`
>> [!success]- Answer
>> b) `2 undefined`
>> Обе функции делят одну запись окружения, поэтому счётчик работает. Но переменная не является свойством объекта — отсюда приватность

> [!question] Что выведет код?
> ```js
> function memo(fn) {
>   const cache = new Map();
>   return x => {
>     if (!cache.has(x)) cache.set(x, fn(x));
>     return cache.get(x);
>   };
> }
> let calls = 0;
> const f = memo(x => { calls++; return x * 2; });
> f(2); f(2); f(3);
> console.log(calls);
> ```
> a) `1`
> b) `2`
> c) `3`
> d) `0`
>> [!success]- Answer
>> b) `2`
>> Второй вызов с тем же аргументом взят из кэша. Опасность в другом: этот Map не имеет вытеснения и растёт неограниченно
