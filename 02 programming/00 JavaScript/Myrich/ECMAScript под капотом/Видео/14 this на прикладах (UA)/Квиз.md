> [!question] Что выведет код?
> ```js
> 'use strict';
> const counter = { n: 0, inc() { this.n++; return this.n; } };
> const detached = counter.inc;
> try { detached(); } catch (e) { console.log(e.constructor.name); }
> ```
> a) `1`
> b) `TypeError`
> c) `ReferenceError`
> d) `NaN`
>> [!success]- Answer
>> b) `TypeError`
>> База вызова потеряна, в строгом режиме получатель равен неопределённому значению, и обращение к его свойству падает

> [!question] Что выведет код?

> ```
> a) `5 5`

> c) `undefined undefined`
> d) `5` затем `TypeError`
>> [!success]- Answer
>> b) `5 undefined`
>> Деструктуризация отрывает метод так же, как присваивание в переменную. Опциональная цепочка спасает от исключения, но значение уже не то

> [!question] Почему слушатель не снимается?
> ```js
> el.addEventListener('click', handler.bind(obj));
> el.removeEventListener('click', handler.bind(obj));
> ```
> a) метод снятия не работает со связанными функциями
> b) связывание создаёт новый объект при каждом вызове
> c) нужно указать третий аргумент
> d) слушатель снимается корректно
>> [!success]- Answer
>> b) связывание создаёт новый объект при каждом вызове
