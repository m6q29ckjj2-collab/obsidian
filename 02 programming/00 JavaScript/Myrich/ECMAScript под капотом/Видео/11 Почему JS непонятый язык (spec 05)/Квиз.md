> [!question] В чём главная причина разрыва между тем, как язык описывают, и тем, как он работает?
> a) язык слишком сложен для точного описания
> b) массовые материалы описывают метафорами, спецификация — алгоритмами
> c) спецификация написана недавно и ещё не разошлась
> d) движки реализуют стандарт по-разному
>> [!success]- Answer
>> b) массовые материалы описывают метафорами, спецификация — алгоритмами
>> Метафора даёт верный прогноз примерно в девяти случаях из десяти и ломается ровно на краевых, которые и спрашивают на собеседованиях

> [!question] Термин «hoisting» присутствует в тексте ECMA-262
>> [!success]- Answer
>> False
>> Есть операции инстанцирования деклараций. Общее правило поиска: переводить фольклорный термин в имя абстрактной операции

> [!question] Значок `?` перед вызовом операции в спецификации — сокращение для операции `___`
>> [!success]- Answer
>> ReturnIfAbrupt
>> Если внутри случился throw, он немедленно пробрасывается наружу. Практическая польза: по расстановке значков видно, где алгоритм может выбросить исключение

> [!question] Что означает восклицательный знак перед вызовом абстрактной операции?
> a) операция обязательно выбросит исключение
> b) исключение здесь невозможно
> c) операция выполняется асинхронно
> d) результат следует проигнорировать
>> [!success]- Answer
>> b) исключение здесь невозможно
>> Это утверждение автора стандарта. Срабатывание такого исключения означало бы ошибку в движке или в самой спецификации

> [!question] Что такое Annex B в стандарте?
> a) список устаревших предложений
> b) приложение, легализующее историческое браузерное поведение
> c) справочник по регулярным выражениям
> d) перечень зарезервированных слов
>> [!success]- Answer
>> b) приложение, легализующее историческое браузерное поведение
>> Оттуда протекающие из блоков функции, строковые методы вроде blink, а также escape и unescape

> [!question] Приложение Annex B можно игнорировать при работе в браузере
>> [!success]- Answer
>> False
>> Формально оно нормативно-опционально для не-браузерных сред, но в браузерах реализовано везде — на практике это обязательная часть языка

> [!question] Почему `typeof null` до сих пор возвращает `'object'`?
> a) это логично с точки зрения системы типов
> b) исправление сломало бы существующий код
> c) так требует стандарт IEEE
> d) в новых версиях это уже исправлено
>> [!success]- Answer
>> b) исправление сломало бы существующий код
>> Ограничение «не сломать веб» сильнее эстетики. За тридцать лет на текущее поведение опёрлись миллионы страниц

> [!question] Официальный набор тестов TC39, полезный как каталог краевых случаев, называется `___`
>> [!success]- Answer
>> Test262
>> На каждое требование стандарта там есть проверка, поэтому он отвечает на вопрос «это требование или деталь реализации»

> [!question] Что требуется предложению для перехода на стадию 4?
> a) одобрение большинством голосов
> b) две независимые реализации и тесты в Test262
> c) хотя бы один прототип в любом движке
> d) публикация статьи с обоснованием
>> [!success]- Answer
>> b) две независимые реализации и тесты в Test262
>> Медлительность процесса — следствие необратимости: ошибку, попавшую в стандарт, нельзя откатить

> [!question] Что показывает эксперимент с хвостовой рекурсией, работающий в Safari и падающий в Chrome?
> a) Safari нарушает стандарт
> b) требование стандарта не выполнено двумя движками из трёх
> c) поведение не описано стандартом вовсе
> d) в Chrome другой предел стека
>> [!success]- Answer
>> b) требование стандарта не выполнено двумя движками из трёх
>> Proper tail calls требуются спецификацией, но реализованы только в JavaScriptCore. Расхождения бывают в обе стороны, поэтому знать нужно и стандарт, и практику

> [!question] Что даёт эксперимент в браузере — требование стандарта или поведение движка?
> a) требование стандарта
> b) поведение конкретного движка
> c) и то, и другое одновременно
> d) зависит от версии браузера
>> [!success]- Answer
>> b) поведение конкретного движка
>> Отсюда порядок работы: сформулировать вопрос в терминах операции, найти её в стандарте, проверить экспериментом, сверить с Test262
