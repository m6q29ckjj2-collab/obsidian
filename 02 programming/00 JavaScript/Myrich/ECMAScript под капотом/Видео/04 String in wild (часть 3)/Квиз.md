> [!question] Что выведет код?
> ```js
> const lone = '\uD800';
> console.log(lone.length, lone.isWellFormed());
> ```
> a) `1 true`
> b) `1 false`
> c) `2 false`
> d) `0 false`
>> [!success]- Answer
>> b) `1 false`
>> Непарный суррогат — совершенно легальная строка длиной в одну единицу, но валидным UTF-16 она не является

> [!question] Как поведут себя три механизма с непарным суррогатом?
> ```js
> const lone = '\uD800';
> ```
> a) все три выбросят исключение
> b) `JSON.stringify` экранирует, `encodeURIComponent` бросит, `TextEncoder` подменит на замещающий символ
> c) все три вернут строку без изменений
> d) все три подменят символ
>> [!success]- Answer
>> b) `JSON.stringify` экранирует, `encodeURIComponent` бросит, `TextEncoder` подменит на замещающий символ
>> Три разные стратегии. Худшая для отладки — тихая подмена: данные портятся молча и всплывает это далеко от причины
