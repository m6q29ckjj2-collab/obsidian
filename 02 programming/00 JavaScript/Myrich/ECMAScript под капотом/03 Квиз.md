> [!question] Инстанцирование деклараций плюс окружение параметров. Что выведет код?
> ```js
> const value = 'внешнее';
> function f(a = value) { var value = 'внутреннее'; return a; }
> console.log(f());
> ```
> a) `внешнее`
> b) `внутреннее`
> c) `undefined`
> d) `ReferenceError`
>> [!success]- Answer
>> a) `внешнее`
>> Наличие значения по умолчанию создаёт отдельное окружение для списка параметров, а тело получает дочернее

> console.log(Object.keys(o).length);
> ```

> b) `3`
> c) `4`
> d) `1`
>> [!success]- Answer
>> a) `2`
