Custom select + portal

Меню телепортируется в document.body (портал), чтобы его не обрезал overflow: hidden родителя. Позиционирование — по принципам Floating UI, без самой библиотеки: координаты считаются в системе документа (position: absolute), поэтому при прокрутке страницы меню едет вместе с кнопкой силами браузера, без участия JS.

2. Внутри собственного скролл-контейнера

Тут селект лежит в блоке со своим overflow-y: auto. Меню в этом случае портируется не в body, а в сам этот контейнер — тогда браузер прокручивает его вместе с содержимым нативно, и JS во время скролла не работает вообще. Покрути внутри рамки и всю страницу — меню остаётся приклеенным к кнопке в обоих случаях. Высота меню при этом ограничивается доступным местом (аналог middleware size), чтобы оно не обрезалось краем контейнера.
