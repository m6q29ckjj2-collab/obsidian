# Swift — задачи на синтаксис (набор 1)

Уровень: новичок. Темы: переменные/константы, типы, optionals, ветвления, циклы, массивы/словари, функции.

Подсказки и решения свёрнуты — щёлкай, чтобы раскрыть. Старайся сначала решить без подсказки, потом сверяйся.

## 1. Переменные и константы

Объяви константу `name` со своим именем (String) и переменную `age` (Int). Выведи в консоль строку вида `Меня зовут Антон, мне 30 лет`, используя интерполяцию строк.

> [!hint]- Подсказка
> - `let` — для констант (не меняются), `var` — для переменных.
> - Интерполяция: `"текст \(переменная) текст"`.

> [!success]- Решение
> ```swift
> let name = "Антон"
> var age = 30
> print("Меня зовут \(name), мне \(age) лет")
> ```

## 2. Типы и вывод типов

Объяви три константы без явного указания типа: `pi` = 3.14, `count` = 5, `isReady` = true. Затем выведи тип каждой через `type(of:)`.

> [!hint]- Подсказка
> Swift сам выведет тип из значения (type inference). Функция `type(of: value)` возвращает тип значения.

> [!success]- Решение
> ```swift
> let pi = 3.14
> let count = 5
> let isReady = true
>
> print(type(of: pi))       // Double
> print(type(of: count))    // Int
> print(type(of: isReady))  // Bool
> ```

## 3. Optional — базовое разворачивание

Есть `var middleName: String? = nil`. Напиши код, который печатает `"Отчество: <значение>"`, если оно есть, иначе печатает `"Отчества нет"`, используя `if let`.

> [!hint]- Подсказка
> - `String?` — optional, может быть `nil`.
> - `if let value = optional { ... } else { ... }` — безопасное разворачивание.

> [!success]- Решение
> ```swift
> var middleName: String? = nil
>
> if let middleName = middleName {
>     print("Отчество: \(middleName)")
> } else {
>     print("Отчества нет")
> }
> ```

## 4. Optional — nil-coalescing

То же самое, что и в задаче 3, но реши в одну строку с помощью оператора `??`, подставляя `"неизвестно"` вместо `nil`.

> [!hint]- Подсказка
> `optional ?? defaultValue` — вернёт значение, если оно есть, иначе — значение по умолчанию.

> [!success]- Решение
> ```swift
> var middleName: String? = nil
> print("Отчество: \(middleName ?? "неизвестно")")
> ```

## 5. Switch по диапазонам

Напиши функцию `grade(for score: Int) -> String`, которая возвращает оценку:
- 90...100 → `"A"`
- 75..<90 → `"B"`
- 60..<75 → `"C"`
- всё остальное → `"F"`

Используй `switch` с диапазонами (`...`, `..<`).

> [!hint]- Подсказка
> В `switch` по числу можно матчить диапазоны прямо в `case`: `case 90...100:`. Не забудь `default`.

> [!success]- Решение
> ```swift
> func grade(for score: Int) -> String {
>     switch score {
>     case 90...100:
>         return "A"
>     case 75..<90:
>         return "B"
>     case 60..<75:
>         return "C"
>     default:
>         return "F"
>     }
> }
>
> print(grade(for: 82)) // B
> ```

## 6. Циклы и массивы

Есть массив `let numbers = [4, 8, 15, 16, 23, 42]`. Посчитай сумму чётных чисел с помощью `for-in` и `if`.

> [!hint]- Подсказка
> Чётность проверяется через `number % 2 == 0`. Заведи переменную-аккумулятор `var sum = 0` до цикла.

> [!success]- Решение
> ```swift
> let numbers = [4, 8, 15, 16, 23, 42]
> var sum = 0
>
> for number in numbers {
>     if number % 2 == 0 {
>         sum += number
>     }
> }
>
> print(sum) // 70
> ```

## 7. То же самое, но функционально

Реши задачу 6 ещё раз, но с помощью `filter` и `reduce`, без явного цикла.

> [!hint]- Подсказка
> - `array.filter { условие }` — оставляет элементы, для которых замыкание вернуло `true`.
> - `array.reduce(0, +)` — суммирует элементы, начиная с 0.

> [!success]- Решение
> ```swift
> let numbers = [4, 8, 15, 16, 23, 42]
> let sum = numbers.filter { $0 % 2 == 0 }.reduce(0, +)
> print(sum) // 70
> ```

## 8. Словари

Есть словарь оценок: `let scores = ["Аня": 85, "Боря": 92, "Вера": 67]`. Выведи имя и оценку каждого в формате `"Аня: 85"`, а также найди имя студента с максимальной оценкой.

> [!hint]- Подсказка
> - Перебор словаря: `for (key, value) in dictionary`.
> - Найти максимум можно через `dictionary.max(by: { $0.value < $1.value })`.

> [!success]- Решение
> ```swift
> let scores = ["Аня": 85, "Боря": 92, "Вера": 67]
>
> for (name, score) in scores {
>     print("\(name): \(score)")
> }
>
> if let best = scores.max(by: { $0.value < $1.value }) {
>     print("Лучший результат: \(best.key) — \(best.value)")
> }
> ```

## 9. Функции с параметрами по умолчанию

Напиши функцию `greet(name: String, greeting: String = "Привет")`, которая печатает `"<greeting>, <name>!"`. Вызови её один раз с двумя аргументами и один раз только с именем.

> [!hint]- Подсказка
> Параметр со значением по умолчанию указывается как `greeting: String = "Привет"` — при вызове его можно опустить.

> [!success]- Решение
> ```swift
> func greet(name: String, greeting: String = "Привет") {
>     print("\(greeting), \(name)!")
> }
>
> greet(name: "Антон", greeting: "Здравствуй")
> greet(name: "Мария")
> ```

## 10. Variadic-параметры

Напиши функцию `average(_ numbers: Double...) -> Double`, которая возвращает среднее арифметическое произвольного количества чисел.

> [!hint]- Подсказка
> Внутри функции `numbers` — это обычный массив `[Double]`. Раздели сумму на `numbers.count`, приведя его к `Double`.

> [!success]- Решение
> ```swift
> func average(_ numbers: Double...) -> Double {
>     guard !numbers.isEmpty else { return 0 }
>     let sum = numbers.reduce(0, +)
>     return sum / Double(numbers.count)
> }
>
> print(average(4, 8, 15, 16, 23, 42)) // 18.0
> ```

## 11. Структуры

Опиши структуру `Point` с полями `x` и `y` (Double). Добавь метод `distance(to other: Point) -> Double`, считающий расстояние между двумя точками.

> [!hint]- Подсказка
> Формула расстояния: √((x1−x2)² + (y1−y2)²). Используй `sqrt(_:)` из Foundation, для степени — `pow(_:_:)` или просто умножение.

> [!success]- Решение
> ```swift
> import Foundation
>
> struct Point {
>     var x: Double
>     var y: Double
>
>     func distance(to other: Point) -> Double {
>         let dx = x - other.x
>         let dy = y - other.y
>         return sqrt(dx * dx + dy * dy)
>     }
> }
>
> let a = Point(x: 0, y: 0)
> let b = Point(x: 3, y: 4)
> print(a.distance(to: b)) // 5.0
> ```

## 12. Enum + switch

Опиши enum `Direction` со случаями `north, south, east, west`. Напиши функцию `opposite(_ direction: Direction) -> Direction`, возвращающую противоположное направление, через `switch`.

> [!hint]- Подсказка
> В `switch` по enum без `default` компилятор заставит перечислить все случаи — это удобно, чтобы ничего не забыть.

> [!success]- Решение
> ```swift
> enum Direction {
>     case north, south, east, west
> }
>
> func opposite(_ direction: Direction) -> Direction {
>     switch direction {
>     case .north: return .south
>     case .south: return .north
>     case .east: return .west
>     case .west: return .east
>     }
> }
>
> print(opposite(.north)) // south
> ```

## 13. Tuples

Напиши функцию `minMax(_ array: [Int]) -> (min: Int, max: Int)?`, которая возвращает кортеж с минимальным и максимальным значением массива, либо `nil`, если массив пуст.

> [!hint]- Подсказка
> Кортеж с именованными полями объявляется как `(min: Int, max: Int)`. Не забудь `guard` на пустой массив.

> [!success]- Решение
> ```swift
> func minMax(_ array: [Int]) -> (min: Int, max: Int)? {
>     guard let first = array.first else { return nil }
>     var currentMin = first
>     var currentMax = first
>     for value in array {
>         if value < currentMin { currentMin = value }
>         if value > currentMax { currentMax = value }
>     }
>     return (min: currentMin, max: currentMax)
> }
>
> if let result = minMax([4, 8, 15, 16, 23, 42]) {
>     print("min: \(result.min), max: \(result.max)")
> }
> ```
