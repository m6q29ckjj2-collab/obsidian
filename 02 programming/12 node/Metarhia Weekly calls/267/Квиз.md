# Квиз — Weekly call #267

**Вопрос 1.** По опросу перед звонком, какой процент участников группы НЕ использует иммутабельные структуры данных?
- A) 15%
- B) 33%
- C) 57%
- D) 82%

Ответ: C) 57%

---

**Вопрос 2.** Согласно правилу, сформулированному на звонке, где предпочтительны мутабельные структуры данных?
- A) В бизнес-логике, для дисциплины
- B) В системном программировании, ради производительности
- C) Везде одинаково, разница не имеет значения
- D) Только в UI-коде

Ответ: B) В системном программировании, ради производительности

---

**Вопрос 3.** Почему Unrolled list на массивах эффективнее классического связного списка для системного кода?
- A) Он проще читать
- B) По массиву дешевле двигать указатель, чем ресайзить сам массив
- C) Он использует меньше строк кода
- D) Node.js предоставляет его из коробки

Ответ: B) По массиву дешевле двигать указатель, чем ресайзить сам массив

**Вопрос 4.** Как `struct` из metautil делает копии объекта, не дублируя все поля?
- A) Через глубокое клонирование (deep clone)
- B) Через сериализацию в JSON и обратно
- C) Через наследование (prototype-chain), храня только диф от родителя

**Вопрос 5.** Какую дополнительную возможность даёт цепочка наследования у `struct`, кроме экономии памяти?

**Вопрос 6.** Что лежит в основе `process.nextTick` в Node.js, упомянутое на звонке как структура для оптимизации?
