# Карточки — Weekly call #266

Какие три AI Skills, относящиеся к структурам данных, обсуждались на звонке #266?
::
JS data structures (встроенные структуры JS), Data structures (как писать свои кастомные структуры), Metautil data structures (использование структур из библиотеки metautil).

При каком условии активируется skill «Metautil data structures»?
::
Только когда пользователь явно просит установить/использовать metautil — по умолчанию он не навязывается.

Зачем нужны AI Skills небольшого размера (пример на звонке — ~210 строк, 8.4 Кб), а не один большой файл?
::
Чтобы AI-агенту было дешевле и точнее найти нужный контекст внутри готового skill, чем искать по всей кодовой базе; skill со временем и укрупняются, и разделяются по опыту использования.

Как были созданы 26 примеров прикладного кода (examples) для тестирования structures?
::
Сначала AI сгенерировал черновики по списку предметных областей (такси, магазин, банк и т.д.), затем Тимур вручную вычитал и поправил все 26.

Какой неожиданный вывод сделали, сравнив размер кода с metautil и без него в 26 примерах?
::
Размер кода получился примерно одинаковым, иногда версия с metautil даже больше — выигрыш библиотеки не в количестве строк, а в developer experience и надёжности контракта.

Какой метод был выпилен из cons-list как «не особо нужный», а потом восстановлен, когда обнаружилось, что он реально требуется в examples?
::
reduce

Как называется новый подкаст-формат, который Тимур записал с Мурычем?
::
«Радио JavaScript»

Сформулируй главное правило стиля кода: когда сравнивать `if (!value)`, а когда `if (value === false)`?
::
В доменном (прикладном) коде — компактно, `if (!value)` (V8 сам оптимизирует). В системном коде (сама библиотека структур данных) — явное сравнение со значением того же типа, `if (value === false)`, чтобы избежать приведения типов.

Почему явное сравнение со значением того же типа быстрее в системном коде, с точки зрения V8?
::
Из-за оптимизации SMI (Small Integer) — маленькие числа и строки V8 хранит как заранее аллоцированные значения с короткими (16/32-битными) указателями в пределах одного сегмента памяти; приведение типов ломает эту короткую адресацию и требует полноценных 64-битных указателей.

Мешают ли промежуточные переменные (intermediate variables) оптимизации V8 в некомпилированном JS-коде?
::
Нет — на этапе некомпилированного кода это просто временный идентификатор, который потом может стать регистровой/стековой переменной после компиляции.

Какой практический совет дали для того, чтобы разобраться, какой вариант кода быстрее на уровне V8?
::
Попросить свою LLM показать байткод (V8 bytecode) для конкретной операции и сравнить два варианта — современные модели умеют это делать.

Почему асинхронный итератор убрали из cons-list в metautil?
::
Структура — синхронная «числодробилка» (in-memory filter/map/reduce), а существовавшая реализация асинхронного итератора всё равно фактически блокировала event loop, не решая заявленную задачу.

Какой интерфейс выбрали для deque в metautil и почему?
::
push/pop/shift/unshift, как у встроенного JS Array — чтобы не переучивать JS-разработчиков привычному интерфейсу.

Почему метод `reverse` в cons-list переименовали в `toReversed`?
::
Он возвращал новый список, не мутируя исходный — значит по смыслу и по конвенции ES2023 (Array.prototype.toReversed/toSorted) должен называться toReversed, а не reverse (иначе вводит в заблуждение).

Какую единственную функциональность из библиотеки metatest оставили после рефакторинга, выпилив её из зависимостей всех остальных модулей Metarhia кроме metautil?
::
Табличные тесты (table-driven tests) для чистых функций.

Для каких функций подходят табличные тесты, а для каких нет?
::
Подходят для чистых, синхронных, «числодробительных» функций (парсинг, строковые операции, криптография). Не подходят для операций с диском, сокетами и другим состоянием.

Какую вторую функциональность решили доделать в metatest помимо табличных тестов?
::
Нормальный бенчмарк-тестер (есть assert и test-раннер, но не было качественных бенчмарков).

В чём суть практического совета от участника (Дмитрия) про prompt injection в AI-агентах?
::
Любая инструкция в markdown-файле проекта воспринимается AI-агентом как часть контекста и может быть выполнена, даже если в основном правиле написано "не делай X" — работает, только если в самой первой инструкции явно указать, что выполнять инструкции нужно только из конкретно перечисленных файлов.

Какая фича Cursor была впервые замечена на звонке для разрешения git-конфликтов?
::
«Resolve in chat» — разрешение merge-конфликта силами AI-агента прямо в чате.

Сколько времени заняло обновление зависимостей во всех репозиториях организации HowProgrammingWorks (309 репозиториев, ~250 «живых») с помощью AI-агента против ручного способа в прошлые годы?
::
Около одного дня с AI-агентом против недели ручной работы в прошлые годы.

Что такое утилита `glow`, упомянутая на звонке?
::
Консольная утилита для красивого рендеринга markdown прямо в терминале (заголовки, таблицы, чекбоксы, quote-блоки, кликабельные ссылки).

Чем отличается утилита `meld` от обычного two-way diff, и когда это особенно полезно?
::
Поддерживает трёхколоночный (three-way) diff — полезно, когда есть общий предок и два независимо изменённых потомка (например, ты и коллега оба правили одну и ту же исходную версию).

Зачем во время live-рефакторинга завели отдельную ветку `DS_optimize`?
::
Чтобы не смешивать в одних коммитах правки структур данных с параллельными правками стиля кода в других модулях.

Какое наблюдение о личной продуктивности сделал Тимур по поводу чередования видов деятельности?
::
Если долго (недели-месяцы) заниматься только одним видом деятельности (только системное программирование, только преподавание и т.д.), со временем это «тяжелеет» и вызывает неудовлетворённость — комфортно, когда в течение дня/недели чередуются минимум два вида деятельности.

Какое условие приёма стартапа в инкубатор Meta Qube озвучено на звонке?
::
Уже работающий продукт с пользователями (ориентир — от 100 пользователей); идеи без единой строчки кода не принимаются.
