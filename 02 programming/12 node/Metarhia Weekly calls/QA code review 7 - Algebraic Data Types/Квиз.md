# Квиз — Q&A and code review #7: Algebraic Data Types

**Вопрос 1.** От какого непринятого TC39-пропозала отталкивается идея звонка?
- A) Pattern Matching
- B) Record & Tuple
- C) Pipeline Operator
- D) Decorators

Ответ: B) Record & Tuple

**Вопрос 2.** В каком языке впервые реализована оригинальная концепция ООП Алана Кея?
- A) Simula
- B) Smalltalk
- C) Lisp
- D) C++

Ответ: B) Smalltalk

**Вопрос 3.** Какие два принципа ООП по Алану Кею исключают race condition по конструкции?
- A) Наследование и полиморфизм
- B) Очередь сообщений, обрабатываемая по одному, и отсутствие прямого доступа к состоянию другого объекта
- C) Инкапсуляция типов и статическая типизация
- D) Множественное наследование и абстрактные классы

Ответ: B) Очередь сообщений, обрабатываемая по одному, и отсутствие прямого доступа к состоянию другого объекта

**Вопрос 4.** Какая архитектура UI впервые появилась в Smalltalk, по замечанию участника со ссылкой на статью Фаулера?

**Вопрос 5.** Через что создаются экземпляры Record в показанной реализации, и почему не через `{}`?
- A) Через `new Object()` — для совместимости
- B) Через `Object.create(null)` — цепочка прототипов заканчивается на null, что чище и быстрее
- C) Через `JSON.parse('{}')` — для валидации
- D) Через Proxy — для перехвата обращений

Ответ: B) Через `Object.create(null)` — цепочка прототипов заканчивается на null, что чище и быстрее

**Вопрос 6.** Чем финализация mutable-варианта Record отличается от immutable?
- A) mutable — Object.freeze, immutable — Object.seal
- B) mutable — Object.seal (можно менять значения полей), immutable — Object.freeze (нельзя менять ничего)
- C) Разницы нет, оба используют Object.freeze
- D) mutable вообще не финализируется

Ответ: B) mutable — Object.seal (можно менять значения полей), immutable — Object.freeze (нельзя менять ничего)

**Вопрос 7.** В чём разница между методами `update` и `fork` у Record?
- A) update создаёт новый экземпляр, fork меняет существующий
- B) update меняет поля существующего экземпляра, fork создаёт новую структуру-потомка
- C) Это синонимы одного и того же метода
- D) update работает только с числами, fork — со строками

Ответ: B) update меняет поля существующего экземпляра, fork создаёт новую структуру-потомка

**Вопрос 8.** Почему TypeScript-типизация для динамически создаваемого Record оказалась малополезной?
- A) TypeScript не поддерживает классы
- B) Реальные поля создаются в рантайме, поэтому типизация вынуждена оперировать unknown/generics без содержательной информации
- C) Record несовместим с TypeScript в принципе
- D) Нужна отдельная лицензия для типизации динамических классов

Ответ: B) Реальные поля создаются в рантайме, поэтому типизация вынуждена оперировать unknown/generics без содержательной информации
