# 13. Что дальше?

← [[12 Виртуальные окружения и пакеты]] · [[00 Оглавление]] · [[14 Интерактивное редактирование ввода и подстановка из истории]] →

Чтение этого руководства, вероятно, укрепило ваш интерес к использованию Python — вам должно хотеться применить Python для решения ваших реальных задач. Куда обратиться, чтобы узнать больше?

Это руководство — часть документации Python. Вот некоторые другие документы из набора:

- Справочник по встроенным объектам Python: подробности о встроенных типах и функциях Python.
- Стандартная библиотека Python: полный (хотя и краткий) справочный материал о типах, функциях и модулях стандартной библиотеки. Стандартный дистрибутив Python включает *очень много* дополнительного кода. Есть модули для чтения почтовых ящиков Unix, получения документов по HTTP, генерации случайных чисел, разбора опций командной строки, сжатия данных и многих других задач. Беглый просмотр Справочника по библиотеке даст вам представление о том, что доступно.
- «Установка модулей Python» объясняет, как устанавливать дополнительные модули, написанные другими пользователями Python.
- Справочник по языку Python: подробное объяснение синтаксиса и семантики Python. Это тяжёлое чтение, но полезное как полное руководство по самому языку.

Другие ресурсы по Python:

- [https://www.python.org](https://www.python.org): главный сайт Python. Он содержит код, документацию и ссылки на связанные с Python страницы по всему вебу.
- [https://docs.python.org](https://docs.python.org): быстрый доступ к документации Python.
- [https://pypi.org](https://pypi.org): Python Package Index, ранее также называвшийся Cheese Shop [^1], — индекс созданных пользователями модулей Python, доступных для скачивания. Когда вы начнёте выпускать код, его можно зарегистрировать здесь, чтобы другие могли его найти.
- [https://code.activestate.com/recipes/langs/python/](https://code.activestate.com/recipes/langs/python/): Python Cookbook — внушительная коллекция примеров кода, более крупных модулей и полезных скриптов. Особенно примечательные вклады собраны в книге с тем же названием Python Cookbook (O'Reilly & Associates, ISBN 0-596-00797-3).
- [https://pyvideo.org](https://pyvideo.org) собирает ссылки на видео о Python с конференций и встреч групп пользователей.
- [https://scipy.org](https://scipy.org): проект Scientific Python включает модули для быстрых вычислений и манипуляций с массивами, а также множество пакетов для таких вещей, как линейная алгебра, преобразования Фурье, нелинейные решатели, распределения случайных чисел, статистический анализ и тому подобное.

По вопросам и сообщениям о проблемах, связанным с Python, можно написать в группу новостей *comp.lang.python* или отправить их в список рассылки python-list@python.org. Группа новостей и список рассылки связаны шлюзом, поэтому сообщения, отправленные в одно, автоматически пересылаются в другое. Там сотни сообщений в день: задают (и отвечают на) вопросы, предлагают новые возможности и анонсируют новые модули. Архивы списка рассылки доступны по адресу [https://mail.python.org/pipermail/](https://mail.python.org/pipermail/).

Перед отправкой сообщения обязательно проверьте список часто задаваемых вопросов (также называемый FAQ). FAQ отвечает на многие вопросы, которые возникают снова и снова, и может уже содержать решение вашей проблемы.

[^1]: «Cheese Shop» — скетч Monty Python: покупатель заходит в сырный магазин, но какой бы сыр он ни попросил, продавец говорит, что его нет.
