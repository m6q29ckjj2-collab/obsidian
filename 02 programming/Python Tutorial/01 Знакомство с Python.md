# 1. Знакомство с Python

← [[00 Оглавление]] · [[02 Интерпретатор Python]] →

Если вы много работаете с компьютером, рано или поздно у вас появится задача, которую хочется автоматизировать. Например, выполнить поиск с заменой в большом количестве текстовых файлов или переименовать и разложить кучу фотографий хитрым образом. Возможно, вы захотите написать небольшую собственную базу данных, специализированное GUI-приложение или простую игру.

Если вы профессиональный разработчик, вам, возможно, приходится работать с несколькими библиотеками на C/C++/Java, и привычный цикл «написать, скомпилировать, протестировать, перекомпилировать» кажется слишком медленным. Возможно, вы пишете набор тестов для такой библиотеки, и сами тесты писать утомительно. Или у вас есть программа, которой пригодился бы встроенный язык расширений, но вы не хотите проектировать и реализовывать для неё целый новый язык.

Тогда Python — как раз то, что вам нужно.

Для некоторых из этих задач можно написать shell-скрипт для Unix или bat-файлы для Windows, но shell-скрипты хороши для перемещения файлов и изменения текстовых данных, а не для GUI-приложений и игр. Можно написать программу на C/C++/Java, но даже черновой вариант займёт много времени разработки. Python проще в использовании, доступен в Windows, macOS и Unix и поможет выполнить работу быстрее.

Python прост в использовании, но это настоящий язык программирования, который даёт гораздо больше структуры и поддержки для больших программ, чем shell-скрипты или bat-файлы. С другой стороны, Python предлагает гораздо больше проверок ошибок, чем C, а, будучи *языком очень высокого уровня*, имеет встроенные высокоуровневые типы данных, такие как гибкие массивы и словари. Благодаря более общим типам данных Python применим к гораздо более широкому кругу задач, чем Awk и даже Perl, при этом многие вещи в нём делаются как минимум так же просто, как и в тех языках.

Python позволяет разбивать программу на модули, которые можно повторно использовать в других программах на Python. В комплекте идёт большая коллекция стандартных модулей, которые можно использовать как основу для своих программ или как примеры для изучения. Некоторые из этих модулей предоставляют файловый ввод-вывод, системные вызовы, сокеты и даже интерфейсы к графическим библиотекам вроде Tk.

Python — интерпретируемый язык, что может заметно сэкономить время при разработке, так как не нужны компиляция и компоновка. Интерпретатор можно использовать интерактивно, что упрощает эксперименты с возможностями языка, написание одноразовых программ или проверку функций при разработке снизу вверх. Это ещё и удобный настольный калькулятор.

Python позволяет писать программы компактно и читаемо. Программы на Python обычно намного короче эквивалентных программ на C, C++ или Java по нескольким причинам:

- высокоуровневые типы данных позволяют выражать сложные операции одной инструкцией;
- группировка инструкций выполняется отступами, а не открывающими и закрывающими скобками;
- не нужны объявления переменных и аргументов.

Python *расширяем*: если вы умеете программировать на C, то легко добавите в интерпретатор новую встроенную функцию или модуль — либо чтобы выполнять критичные операции на максимальной скорости, либо чтобы связать программы на Python с библиотеками, доступными только в бинарном виде (например, с графической библиотекой конкретного производителя). Когда вы по-настоящему втянетесь, вы сможете встроить интерпретатор Python в приложение на C и использовать его как язык расширений или команд для этого приложения.

Кстати, язык назван в честь шоу BBC «Monty Python's Flying Circus» и не имеет отношения к рептилиям. Ссылаться на скетчи Monty Python в документации не только разрешено, но и приветствуется!

Теперь, когда вы воодушевлены, самое время рассмотреть Python подробнее. Поскольку лучший способ выучить язык — использовать его, руководство предлагает вам поиграть с интерпретатором по ходу чтения.

В следующей главе объясняется, как пользоваться интерпретатором. Это довольно скучная информация, но она необходима, чтобы пробовать примеры, которые приводятся дальше.

Остальная часть руководства знакомит с разными возможностями языка и системы на примерах: начиная с простых выражений, инструкций и типов данных, через функции и модули и заканчивая продвинутыми понятиями вроде исключений и пользовательских классов.
