## 10.1. Интерфейс операционной системы

Модуль `os` предоставляет десятки функций для взаимодействия с операционной системой:

```python
>>> import os
>>> os.getcwd()      # Return the current working directory
'C:\\Python315'
>>> os.chdir('/server/accesslogs')   # Change current working directory
>>> os.system('mkdir today')   # Run the command mkdir in the system shell
0
```

Обязательно используйте стиль `import os` вместо `from os import *`. Это не даст `os.open()` затенить встроенную функцию `open()`, которая работает совсем иначе.

Встроенные функции `dir()` и `help()` полезны как интерактивные помощники при работе с большими модулями вроде `os`:

```python
>>> import os
>>> dir(os)
<returns a list of all module functions>
>>> help(os)
<returns an extensive manual page created from the module's docstrings>
```

Для повседневных задач управления файлами и каталогами модуль `shutil` предоставляет интерфейс более высокого уровня, который проще в использовании:

```python
>>> import shutil
>>> shutil.copyfile('data.db', 'archive.db')
'archive.db'
>>> shutil.move('/build/executables', 'installdir')
'installdir'
```

## 10.2. Шаблоны имён файлов

Модуль `glob` предоставляет функцию для составления списков файлов по поиску с шаблонами в каталоге:

```python
>>> import glob
>>> glob.glob('*.py')
['primes.py', 'random.py', 'quote.py']
```

## 10.3. Аргументы командной строки

Типичным служебным скриптам часто нужно обрабатывать аргументы командной строки. Эти аргументы хранятся в атрибуте *argv* модуля `sys` в виде списка. Например, возьмём следующий файл `demo.py`:

```python
# File demo.py
import sys
print(sys.argv)
```

Вот вывод запуска `python demo.py one two three` в командной строке:

```python
['demo.py', 'one', 'two', 'three']
```

Модуль `argparse` предоставляет более продвинутый механизм обработки аргументов командной строки. Следующий скрипт извлекает одно или несколько имён файлов и необязательное количество выводимых строк:

```python
import argparse

parser = argparse.ArgumentParser(
    prog='top',
    description='Show top lines from each file')
parser.add_argument('filenames', nargs='+')
parser.add_argument('-l', '--lines', type=int, default=10)
args = parser.parse_args()
print(args)
```

При запуске в командной строке как `python top.py --lines=5 alpha.txt beta.txt` скрипт устанавливает `args.lines` в `5`, а `args.filenames` — в `['alpha.txt', 'beta.txt']`.

## 10.4. Перенаправление вывода ошибок и завершение программы

У модуля `sys` есть также атрибуты для *stdin*, *stdout* и *stderr*. Последний полезен для вывода предупреждений и сообщений об ошибках, чтобы они были видны, даже когда *stdout* перенаправлен:

```python
>>> sys.stderr.write('Warning, log file not found starting a new one\n')
Warning, log file not found starting a new one
```

Самый прямой способ завершить скрипт — использовать `sys.exit()`.

## 10.5. Сопоставление строк с шаблоном

Модуль `re` предоставляет инструменты регулярных выражений для продвинутой обработки строк. Для сложного сопоставления и преобразования регулярные выражения предлагают краткие, оптимизированные решения:

```python
>>> import re
>>> re.findall(r'\bf[a-z]*', 'which foot or hand fell fastest')
['foot', 'fell', 'fastest']
>>> re.sub(r'(\b[a-z]+) \1', r'\1', 'cat in the the hat')
'cat in the hat'
```

Когда нужны только простые возможности, предпочтительнее строковые методы, потому что их проще читать и отлаживать:

```python
>>> 'tea for too'.replace('too', 'two')
'tea for two'
```

## 10.6. Математика

Модуль `math` даёт доступ к функциям базовой библиотеки C для математики с плавающей точкой:

```python
>>> import math
>>> math.cos(math.pi / 4)
0.70710678118654757
>>> math.log(1024, 2)
10.0
```

Модуль `random` предоставляет инструменты для случайного выбора:

```python
>>> import random
>>> random.choice(['apple', 'pear', 'banana'])
'apple'
>>> random.sample(range(100), 10)   # sampling without replacement
[30, 83, 16, 4, 8, 81, 41, 50, 18, 33]
>>> random.random()    # random float from the interval [0.0, 1.0)
0.17970987693706186
>>> random.randrange(6)    # random integer chosen from range(6)
4
```

Модуль `statistics` вычисляет базовые статистические характеристики (среднее, медиану, дисперсию и т. д.) числовых данных:

```python
>>> import statistics
>>> data = [2.75, 1.75, 1.25, 0.25, 0.5, 1.25, 3.5]
>>> statistics.mean(data)
1.6071428571428572
>>> statistics.median(data)
1.25
>>> statistics.variance(data)
1.3720238095238095
```

В проекте SciPy <[https://scipy.org](https://scipy.org)> есть много других модулей для численных вычислений.

## 10.7. Доступ в интернет

Есть ряд модулей для доступа в интернет и обработки интернет-протоколов. Два самых простых — `urllib.request` для получения данных по URL и `smtplib` для отправки почты:

```python
>>> from urllib.request import urlopen
>>> with urlopen('https://docs.python.org/3/') as response:
...     for line in response:
...         line = line.decode()             # Convert bytes to a str
...         if 'updated' in line:
...             print(line.rstrip())         # Remove trailing newline
...
      Last updated on Nov 11, 2025 (20:11 UTC).

>>> import smtplib
>>> server = smtplib.SMTP('localhost')
>>> server.sendmail('soothsayer@example.org', 'jcaesar@example.org',
... """To: jcaesar@example.org
... From: soothsayer@example.org
...
... Beware the Ides of March.
... """)
>>> server.quit()
```

(Обратите внимание, что для второго примера нужен почтовый сервер, запущенный на localhost.)

## 10.8. Даты и время

Модуль `datetime` предоставляет классы для работы с датами и временем как простыми, так и сложными способами. Хотя арифметика дат и времени поддерживается, главный упор в реализации сделан на эффективное извлечение полей для форматирования вывода и обработки. Модуль также поддерживает объекты, учитывающие часовой пояс.

```python
>>> # dates are easily constructed and formatted
>>> import datetime as dt
>>> now = dt.date.today()
>>> now
datetime.date(2003, 12, 2)
>>> now.strftime("%m-%d-%y. %d %b %Y is a %A on the %d day of %B.")
'12-02-03. 02 Dec 2003 is a Tuesday on the 02 day of December.'

>>> # dates support calendar arithmetic
>>> birthday = dt.date(1964, 7, 31)
>>> age = now - birthday
>>> age.days
14368
```

## 10.9. Сжатие данных

Распространённые форматы архивации и сжатия данных поддерживаются напрямую модулями, в том числе: `zlib`, `gzip`, `bz2`, `lzma`, `zipfile` и `tarfile`.

```python
>>> import zlib
>>> s = b'witch which has which witches wrist watch'
>>> len(s)
41
>>> t = zlib.compress(s)
>>> len(t)
37
>>> zlib.decompress(t)
b'witch which has which witches wrist watch'
>>> zlib.crc32(s)
226805979
```

## 10.10. Измерение производительности

Некоторые пользователи Python глубоко интересуются относительной производительностью разных подходов к одной и той же задаче. Python предоставляет инструмент измерения, который сразу отвечает на такие вопросы.

Например, может возникнуть соблазн использовать упаковку и распаковку кортежей вместо традиционного способа обмена значениями. Модуль `timeit` быстро показывает скромное преимущество в производительности:

```python
>>> from timeit import Timer
>>> Timer('t=a; a=b; b=t', 'a=1; b=2').timeit()
0.57535828626024577
>>> Timer('a,b = b,a', 'a=1; b=2').timeit()
0.54962537085770791
```

В отличие от мелкой детализации `timeit`, модули `profile` и `pstats` предоставляют инструменты для выявления критичных по времени участков в более крупных блоках кода.

## 10.11. Контроль качества

Один из подходов к разработке качественного ПО — писать тесты для каждой функции по мере её разработки и часто запускать эти тесты в процессе разработки.

Модуль `doctest` предоставляет инструмент для сканирования модуля и проверки тестов, встроенных в docstring программы. Составление теста так же просто, как вырезать и вставить типичный вызов вместе с его результатами в docstring. Это улучшает документацию, предоставляя пользователю пример, и позволяет модулю doctest убедиться, что код остаётся верным документации:

```python
def average(values):
    """Computes the arithmetic mean of a list of numbers.

    >>> print(average([20, 30, 70]))
    40.0
    """
    return sum(values) / len(values)

import doctest
doctest.testmod()   # automatically validate the embedded tests
```

Модуль `unittest` не так прост, как `doctest`, но позволяет поддерживать более полный набор тестов в отдельном файле:

```python
import unittest

class TestStatisticalFunctions(unittest.TestCase):

    def test_average(self):
        self.assertEqual(average([20, 30, 70]), 40.0)
        self.assertEqual(round(average([1, 5, 7]), 1), 4.3)
        with self.assertRaises(ZeroDivisionError):
            average([])
        with self.assertRaises(TypeError):
            average(20, 30, 70)

unittest.main()  # Calling from the command line invokes all tests
```

## 10.12. «Батарейки в комплекте»

У Python философия «батарейки в комплекте». Лучше всего это видно по сложным и надёжным возможностям его более крупных пакетов. Например:

- Модули `xmlrpc.client` и `xmlrpc.server` превращают реализацию удалённых вызовов процедур в почти тривиальную задачу. Несмотря на названия модулей, прямые знания об XML и работа с ним не требуются.
- Пакет `email` — библиотека для управления сообщениями электронной почты, включая MIME и другие документы сообщений на основе [**RFC 5322**](https://datatracker.ietf.org/doc/html/rfc5322.html). В отличие от `smtplib` и `poplib`, которые фактически отправляют и получают сообщения, пакет email содержит полный набор инструментов для построения или декодирования сложных структур сообщений (включая вложения) и для реализации интернет-кодировок и протоколов заголовков.
- Пакет `json` обеспечивает надёжную поддержку разбора этого популярного формата обмена данными. Модуль `csv` поддерживает прямое чтение и запись файлов в формате значений, разделённых запятыми, который широко поддерживается базами данных и электронными таблицами. Обработка XML поддерживается пакетами `xml.etree.ElementTree`, `xml.dom` и `xml.sax`. Вместе эти модули и пакеты значительно упрощают обмен данными между приложениями на Python и другими инструментами.
- Модуль `sqlite3` — обёртка библиотеки баз данных SQLite, предоставляющая постоянную базу данных, которую можно обновлять и к которой можно обращаться с помощью слегка нестандартного синтаксиса SQL.
- Интернационализация поддерживается рядом модулей, в том числе `gettext`, `locale` и пакетом `codecs`.
