# 7. Ввод и вывод

← [[06 Модули]] · [[00 Оглавление]] · [[08 Ошибки и исключения]] →

Есть несколько способов представить вывод программы: данные можно вывести в удобочитаемой форме или записать в файл для дальнейшего использования. В этой главе обсуждаются некоторые из возможностей.

## 7.1. Более изящное форматирование вывода

Пока что мы встречали два способа вывода значений: *инструкции-выражения* и функцию `print()`. (Третий способ — метод `write()` файловых объектов; стандартный выходной файл доступен как `sys.stdout`. Подробнее см. Справочник по библиотеке.)

Часто нужно больше контроля над форматированием вывода, чем простая печать значений через пробел. Есть несколько способов форматирования вывода.

- Чтобы использовать форматированные строковые литералы, начните строку с `f` или `F` перед открывающей кавычкой или тройной кавычкой. Внутри такой строки между символами `{` и `}` можно писать выражение Python, которое может ссылаться на переменные или литеральные значения.

  ```python
  >>> year = 2016
  >>> event = 'Referendum'
  >>> f'Results of the {year} {event}'
  'Results of the 2016 Referendum'
  ```
- Метод строк `str.format()` требует больше ручной работы. Вы по-прежнему используете `{` и `}`, чтобы отметить, куда будет подставлена переменная, и можете задавать подробные директивы форматирования, но вам также придётся передать информацию, которую нужно форматировать. В следующем блоке кода два примера форматирования переменных:

  ```python
  >>> yes_votes = 42_572_654
  >>> total_votes = 85_705_149
  >>> percentage = yes_votes / total_votes
  >>> '{:-9} YES votes  {:2.2%}'.format(yes_votes, percentage)
  ' 42572654 YES votes  49.67%'
  ```

  Обратите внимание, как `yes_votes` дополняется пробелами, а знак «минус» выводится только для отрицательных чисел. Пример также выводит `percentage`, умноженный на 100, с 2 знаками после запятой и знаком процента (подробности — в мини-языке спецификации формата).
- Наконец, можно выполнять всю обработку строк самостоятельно, используя срезы строк и операции конкатенации для создания любой мыслимой раскладки. У строкового типа есть методы, выполняющие полезные операции по дополнению строк до заданной ширины столбца.

Когда вам не нужен изысканный вывод, а нужно просто быстро показать несколько переменных для отладки, любое значение можно преобразовать в строку функциями `repr()` или `str()`.

Функция `str()` предназначена для возврата представлений значений, достаточно удобочитаемых для человека, а `repr()` — для генерации представлений, которые может прочитать интерпретатор (или которые вызовут `SyntaxError`, если эквивалентного синтаксиса нет). Для объектов, у которых нет особого представления для человека, `str()` вернёт то же значение, что и `repr()`. Многие значения, такие как числа или структуры вроде списков и словарей, имеют одинаковое представление при использовании любой из функций. Строки, в частности, имеют два разных представления.

Несколько примеров:

```python
>>> s = 'Hello, world.'
>>> str(s)
'Hello, world.'
>>> repr(s)
"'Hello, world.'"
>>> str(1/7)
'0.14285714285714285'
>>> x = 10 * 3.25
>>> y = 200 * 200
>>> s = 'The value of x is ' + repr(x) + ', and y is ' + repr(y) + '...'
>>> print(s)
The value of x is 32.5, and y is 40000...
>>> # The repr() of a string adds string quotes and backslashes:
>>> hello = 'hello, world\n'
>>> hellos = repr(hello)
>>> print(hellos)
'hello, world\n'
>>> # The argument to repr() may be any Python object:
>>> repr((x, y, ('spam', 'eggs')))
"(32.5, 40000, ('spam', 'eggs'))"
```

Модуль `string` содержит поддержку простого подхода к шаблонизации на основе регулярных выражений через `string.Template`. Это ещё один способ подстановки значений в строки: используются заполнители вроде `$x`, которые заменяются значениями из словаря. Этот синтаксис прост в использовании, хотя даёт гораздо меньше контроля над форматированием.

### 7.1.1. Форматированные строковые литералы

Форматированные строковые литералы (для краткости также называемые f-строками) позволяют включать значения выражений Python внутрь строки: нужно поставить перед строкой `f` или `F` и записывать выражения как `{expression}`.

После выражения может следовать необязательный спецификатор формата. Он даёт больше контроля над тем, как форматируется значение. Следующий пример округляет число пи до трёх знаков после запятой:

```python
>>> import math
>>> print(f'The value of pi is approximately {math.pi:.3f}.')
The value of pi is approximately 3.142.
```

Если после `':'` передать целое число, поле получит минимальную ширину в столько символов. Это полезно для выравнивания столбцов.

```python
>>> table = {'Sjoerd': 4127, 'Jack': 4098, 'Dcab': 7678}
>>> for name, phone in table.items():
...     print(f'{name:10} ==> {phone:10d}')
...
Sjoerd     ==>       4127
Jack       ==>       4098
Dcab       ==>       7678
```

Другие модификаторы можно использовать для преобразования значения перед форматированием. `'!a'` применяет `ascii()`, `'!s'` применяет `str()`, а `'!r'` применяет `repr()`:

```python
>>> animals = 'eels'
>>> print(f'My hovercraft is full of {animals}.')
My hovercraft is full of eels.
>>> print(f'My hovercraft is full of {animals!r}.')
My hovercraft is full of 'eels'.
```

Спецификатор `=` разворачивает выражение в текст выражения, знак равенства и затем представление вычисленного выражения:

```python
>>> bugs = 'roaches'
>>> count = 13
>>> area = 'living room'
>>> print(f'Debugging {bugs=} {count=} {area=}')
Debugging bugs='roaches' count=13 area='living room'
```

Подробнее о спецификаторе `=` см. раздел о самодокументирующихся выражениях. Справочник по этим спецификациям формата — в описании мини-языка спецификации формата.

### 7.1.2. Метод строк format()

Базовое использование метода `str.format()` выглядит так:

```python
>>> print('We are the {} who say "{}!"'.format('knights', 'Ni'))
We are the knights who say "Ni!"
```

Скобки и символы внутри них (называемые полями формата) заменяются объектами, переданными в метод `str.format()`. Число в скобках можно использовать для указания позиции объекта, переданного в метод `str.format()`.

```python
>>> print('{0} and {1}'.format('spam', 'eggs'))
spam and eggs
>>> print('{1} and {0}'.format('spam', 'eggs'))
eggs and spam
```

Если в методе `str.format()` используются именованные аргументы, на их значения ссылаются по имени аргумента.

```python
>>> print('This {food} is {adjective}.'.format(
...       food='spam', adjective='absolutely horrible'))
This spam is absolutely horrible.
```

Позиционные и именованные аргументы можно произвольно комбинировать:

```python
>>> print('The story of {0}, {1}, and {other}.'.format('Bill', 'Manfred',
...                                                    other='Georg'))
The story of Bill, Manfred, and Georg.
```

Если у вас действительно длинная форматная строка, которую не хочется разбивать, было бы здорово ссылаться на форматируемые переменные по имени, а не по позиции. Это можно сделать, просто передав словарь и используя квадратные скобки `'[]'` для доступа к ключам.

```python
>>> table = {'Sjoerd': 4127, 'Jack': 4098, 'Dcab': 8637678}
>>> print('Jack: {0[Jack]:d}; Sjoerd: {0[Sjoerd]:d}; '
...       'Dcab: {0[Dcab]:d}'.format(table))
Jack: 4098; Sjoerd: 4127; Dcab: 8637678
```

То же самое можно сделать, передав словарь `table` как именованные аргументы через запись `**`.

```python
>>> table = {'Sjoerd': 4127, 'Jack': 4098, 'Dcab': 8637678}
>>> print('Jack: {Jack:d}; Sjoerd: {Sjoerd:d}; Dcab: {Dcab:d}'.format(**table))
Jack: 4098; Sjoerd: 4127; Dcab: 8637678
```

Это особенно полезно в сочетании со встроенной функцией `vars()`, которая возвращает словарь со всеми локальными переменными:

```python
>>> table = {k: str(v) for k, v in vars().items()}
>>> message = " ".join([f'{k}: ' + '{' + k +'};' for k in table.keys()])
>>> print(message.format(**table))
__name__: __main__; __doc__: None; __package__: None; __loader__: ...
```

В качестве примера следующие строки создают аккуратно выровненный набор столбцов с целыми числами, их квадратами и кубами:

```python
>>> for x in range(1, 11):
...     print('{0:2d} {1:3d} {2:4d}'.format(x, x*x, x*x*x))
...
 1   1    1
 2   4    8
 3   9   27
 4  16   64
 5  25  125
 6  36  216
 7  49  343
 8  64  512
 9  81  729
10 100 1000
```

Полный обзор форматирования строк через `str.format()` — в разделе о синтаксисе форматной строки.

### 7.1.3. Ручное форматирование строк

Вот та же таблица квадратов и кубов, отформатированная вручную:

```python
>>> for x in range(1, 11):
...     print(repr(x).rjust(2), repr(x*x).rjust(3), end=' ')
...     # Note use of 'end' on previous line
...     print(repr(x*x*x).rjust(4))
...
 1   1    1
 2   4    8
 3   9   27
 4  16   64
 5  25  125
 6  36  216
 7  49  343
 8  64  512
 9  81  729
10 100 1000
```

(Заметьте, что один пробел между столбцами добавлен тем, как работает `print()`: она всегда добавляет пробелы между аргументами.)

Метод `str.rjust()` строковых объектов выравнивает строку по правому краю в поле заданной ширины, дополняя её пробелами слева. Есть похожие методы `str.ljust()` и `str.center()`. Эти методы ничего не выводят, а просто возвращают новую строку. Если входная строка слишком длинная, они её не обрезают, а возвращают без изменений; это испортит раскладку столбцов, но обычно лучше альтернативы, то есть искажения значения. (Если вам действительно нужно обрезание, всегда можно добавить операцию среза, как в `x.ljust(n)[:n]`.)

Есть и другой метод, `str.zfill()`, который дополняет числовую строку нулями слева. Он понимает знаки «плюс» и «минус»:

```python
>>> '12'.zfill(5)
'00012'
>>> '-3.14'.zfill(7)
'-003.14'
>>> '3.14159265359'.zfill(5)
'3.14159265359'
```

### 7.1.4. Старое форматирование строк

Оператор % (остаток от деления) тоже можно использовать для форматирования строк. Для `format % values` (где *format* — строка) спецификации преобразования `%` в *format* заменяются нулём или более элементов *values*. Эта операция широко известна как интерполяция строк. Например:

```python
>>> import math
>>> print('The value of pi is approximately %5.3f.' % math.pi)
The value of pi is approximately 3.142.
```

Дополнительную информацию можно найти в разделе о форматировании строк в стиле printf.

## 7.2. Чтение и запись файлов

`open()` возвращает файловый объект и чаще всего используется с двумя позиционными аргументами: `open(filename, mode)`

```python
>>> f = open('workfile', 'w')
```

Первый аргумент — строка с именем файла. Второй аргумент — другая строка из нескольких символов, описывающая, как файл будет использоваться. *mode* может быть `'r'`, если файл будет только читаться, `'w'` — только для записи (существующий файл с тем же именем будет стёрт), а `'a'` открывает файл для дозаписи; любые данные, записанные в файл, автоматически добавляются в конец. `'r+'` открывает файл и для чтения, и для записи. Аргумент *mode* необязателен; если он опущен, предполагается `'r'`.

Обычно файлы открываются в *текстовом режиме*, то есть вы читаете и записываете в файл и из файла строки, закодированные в определённой *кодировке*. Если *encoding* не указана, по умолчанию используется UTF-8 (см. `open()`). Добавление `'b'` к режиму открывает файл в *двоичном режиме*. Данные в двоичном режиме читаются и записываются как объекты `bytes`. При открытии файла в двоичном режиме указывать *encoding* нельзя.

В текстовом режиме при чтении по умолчанию зависящие от платформы окончания строк (`\n` в Unix, `\r\n` в Windows) преобразуются в просто `\n`. При записи в текстовом режиме по умолчанию `\n` преобразуются обратно в зависящие от платформы окончания строк. Такое скрытое изменение данных файла нормально для текстовых файлов, но испортит двоичные данные, например в файлах `JPEG` или `EXE`. Будьте очень осторожны и используйте двоичный режим при чтении и записи таких файлов.

Хорошая практика — использовать ключевое слово `with` при работе с файловыми объектами. Преимущество в том, что файл корректно закрывается после завершения его блока, даже если в какой-то момент возникло исключение. Использование `with` также гораздо короче, чем написание эквивалентных блоков `try`-`finally`:

```python
>>> with open('workfile') as f:
...     read_data = f.read()

>>> # We can check that the file has been automatically closed.
>>> f.closed
True
```

Если вы не используете ключевое слово `with`, то нужно вызвать `f.close()`, чтобы закрыть файл и немедленно освободить все использованные им системные ресурсы.

> [!warning] Предупреждение
> Вызов `f.write()` без использования ключевого слова `with` или вызова `f.close()` **может** привести к тому, что аргументы `f.write()` не будут полностью записаны на диск, даже если программа завершилась успешно.

После закрытия файлового объекта, инструкцией `with` или вызовом `f.close()`, попытки использовать файловый объект автоматически завершаются ошибкой.

```python
>>> f.close()
>>> f.read()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
ValueError: I/O operation on closed file.
```

### 7.2.1. Методы файловых объектов

В остальных примерах этого раздела предполагается, что файловый объект `f` уже создан.

Чтобы прочитать содержимое файла, вызовите `f.read(size)`, который читает некоторое количество данных и возвращает их в виде строки (в текстовом режиме) или объекта bytes (в двоичном режиме). *size* — необязательный числовой аргумент. Если *size* опущен или отрицателен, будет прочитано и возвращено всё содержимое файла; если файл вдвое больше памяти вашей машины, это ваша проблема. В противном случае читается и возвращается не более *size* символов (в текстовом режиме) или *size* байтов (в двоичном режиме). Если достигнут конец файла, `f.read()` вернёт пустую строку (`''`).

```python
>>> f.read()
'This is the entire file.\n'
>>> f.read()
''
```

`f.readline()` читает из файла одну строку; символ новой строки (`\n`) остаётся в конце строки и опускается только в последней строке файла, если файл не заканчивается переводом строки. Это делает возвращаемое значение однозначным; если `f.readline()` возвращает пустую строку, достигнут конец файла, а пустая строка представляется как `'\n'` — строка, содержащая только один перевод строки.

```python
>>> f.readline()
'This is the first line of the file.\n'
>>> f.readline()
'Second line of the file\n'
>>> f.readline()
''
```

Для чтения строк из файла можно выполнить цикл по файловому объекту. Это эффективно по памяти, быстро и приводит к простому коду:

```python
>>> for line in f:
...     print(line, end='')
...
This is the first line of the file.
Second line of the file
```

Если вы хотите прочитать все строки файла в список, можно также использовать `list(f)` или `f.readlines()`.

`f.write(string)` записывает содержимое строки *string* в файл, возвращая количество записанных символов.

```python
>>> f.write('This is a test\n')
15
```

Объекты других типов нужно преобразовать — в строку (в текстовом режиме) или в объект bytes (в двоичном режиме) — перед записью:

```python
>>> value = ('the answer', 42)
>>> s = str(value)  # convert the tuple to string
>>> f.write(s)
18
```

`f.tell()` возвращает целое число, задающее текущую позицию файлового объекта в файле: в двоичном режиме — число байтов от начала файла, в текстовом режиме — непрозрачное число.

Чтобы изменить позицию файлового объекта, используйте `f.seek(offset, whence)`. Позиция вычисляется прибавлением *offset* к точке отсчёта; точка отсчёта выбирается аргументом *whence*. Значение *whence*, равное 0, отсчитывает от начала файла, 1 использует текущую позицию в файле, а 2 использует конец файла как точку отсчёта. *whence* можно опустить, по умолчанию он равен 0, то есть точкой отсчёта служит начало файла.

```python
>>> f = open('workfile', 'rb+')
>>> f.write(b'0123456789abcdef')
16
>>> f.seek(5)      # Go to the 6th byte in the file
5
>>> f.read(1)
b'5'
>>> f.seek(-3, 2)  # Go to the 3rd byte before the end
13
>>> f.read(1)
b'd'
```

В текстовых файлах (открытых без `b` в строке режима) разрешены только переходы относительно начала файла (исключение — переход в самый конец файла через `seek(0, 2)`), а единственные допустимые значения *offset* — те, что возвращены `f.tell()`, или ноль. Любое другое значение *offset* приводит к неопределённому поведению.

У файловых объектов есть и дополнительные методы, такие как `isatty()` и `truncate()`, которые используются реже; полное руководство по файловым объектам — в Справочнике по библиотеке.

### 7.2.2. Сохранение структурированных данных с помощью `json`

Строки легко записывать в файл и читать из него. С числами требуется чуть больше усилий, так как метод `read()` возвращает только строки, которые придётся передать функции вроде `int()`, принимающей строку `'123'` и возвращающей её числовое значение 123. Когда нужно сохранить более сложные типы данных, такие как вложенные списки и словари, разбор и сериализация вручную становятся сложными.

Чтобы пользователям не приходилось постоянно писать и отлаживать код для сохранения сложных типов данных в файлы, Python позволяет использовать популярный формат обмена данными [JSON (JavaScript Object Notation)](https://json.org). Стандартный модуль `json` может взять иерархии данных Python и преобразовать их в строковые представления; этот процесс называется *сериализацией*. Восстановление данных из строкового представления называется *десериализацией*. Между сериализацией и десериализацией строка, представляющая объект, могла быть сохранена в файле или в данных, либо отправлена по сети на какую-нибудь удалённую машину.

> [!note] Примечание
> Формат JSON широко используется современными приложениями для обмена данными. Многие программисты уже с ним знакомы, что делает его хорошим выбором для интероперабельности.

Если у вас есть объект `x`, его строковое представление в JSON можно увидеть одной простой строкой кода:

```python
>>> import json
>>> x = [1, 'simple', 'list']
>>> json.dumps(x)
'[1, "simple", "list"]'
```

Другой вариант функции `dumps()`, называемый `dump()`, просто сериализует объект в текстовый файл. Так что если `f` — текстовый файловый объект, открытый для записи, можно сделать так:

```python
json.dump(x, f)
```

Чтобы снова декодировать объект, если `f` — двоичный или текстовый файловый объект, открытый для чтения:

```python
x = json.load(f)
```

> [!note] Примечание
> Файлы JSON должны быть закодированы в UTF-8 — кодировке по умолчанию для текстовых файлов.

Эта простая техника сериализации справляется со списками и словарями, но сериализация произвольных экземпляров классов в JSON требует небольших дополнительных усилий. Объяснение этого есть в справочнике по модулю `json`.

> [!note] См. также
> `pickle` — модуль pickle
>
> В отличие от JSON, *pickle* — протокол, позволяющий сериализовать сколь угодно сложные объекты Python. Поэтому он специфичен для Python и не может использоваться для связи с приложениями, написанными на других языках. Кроме того, он небезопасен по умолчанию: десериализация данных pickle из недоверенного источника может выполнить произвольный код, если данные были подготовлены опытным злоумышленником.
