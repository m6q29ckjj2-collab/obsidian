# 14. Интерактивное редактирование ввода и подстановка из истории

← [[13 Что дальше]] · [[00 Оглавление]] · [[15 Арифметика с плавающей точкой — проблемы и ограничения]] →

Некоторые версии интерпретатора Python поддерживают редактирование текущей строки ввода и подстановку из истории, подобно возможностям оболочек Korn shell и GNU Bash. Это реализовано с помощью библиотеки [GNU Readline](https://tiswww.case.edu/php/chet/readline/rltop.html), которая поддерживает различные стили редактирования. У этой библиотеки есть собственная документация, которую мы здесь дублировать не будем.

## 14.1. Автодополнение по Tab и редактирование истории

Автодополнение имён переменных и модулей автоматически включается при запуске интерпретатора, так что клавиша Tab вызывает функцию дополнения; она просматривает имена инструкций Python, текущие локальные переменные и доступные имена модулей. Для выражений с точками, таких как `string.a`, она вычислит выражение до последней `'.'`, а затем предложит варианты дополнения из атрибутов получившегося объекта. Учтите, что это может выполнить код, определённый приложением, если в выражении участвует объект с методом `__getattr__()`. Конфигурация по умолчанию также сохраняет вашу историю в файл `.python_history` в вашем пользовательском каталоге. История снова будет доступна в следующем интерактивном сеансе интерпретатора.

## 14.2. Альтернативы интерактивному интерпретатору

Эта возможность — огромный шаг вперёд по сравнению с более ранними версиями интерпретатора; однако некоторые пожелания остались: было бы хорошо, если бы на строках продолжения предлагался правильный отступ (парсер знает, требуется ли следующим токен `INDENT`). Механизм дополнения мог бы использовать таблицу символов интерпретатора. Команда для проверки (или даже предложения) парных скобок, кавычек и т. д. тоже была бы полезна.

Одна из альтернативных улучшенных интерактивных оболочек, существующая уже довольно давно, — [IPython](https://ipython.org/), в которой есть автодополнение по Tab, исследование объектов и продвинутое управление историей. Её также можно тщательно настраивать и встраивать в другие приложения. Другая похожая улучшенная интерактивная среда — [bpython](https://bpython-interpreter.org/).
