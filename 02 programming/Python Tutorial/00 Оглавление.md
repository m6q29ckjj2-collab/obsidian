# Руководство по Python (Python 3.15)

Перевод официального руководства [The Python Tutorial](https://docs.python.org/3.15/tutorial/index.html) на русский язык. Ссылки на другие разделы документации (справочник по библиотеке, справочник по языку и т. д.) в переводе сохранены в виде обычного текста; оригинальные ссылки смотрите в английской версии.

> [!tip] Подсказка
> Это руководство предназначено для *программистов*, которые только знакомятся с языком Python, а **не** для *новичков в программировании*.

Python — простой в изучении, мощный язык программирования. В нём есть эффективные высокоуровневые структуры данных и простой, но действенный подход к объектно-ориентированному программированию. Элегантный синтаксис Python и динамическая типизация вместе с интерпретируемой природой делают его идеальным языком для написания скриптов и быстрой разработки приложений во многих областях на большинстве платформ.

Интерпретатор Python и обширная стандартная библиотека свободно доступны в исходном или бинарном виде для всех основных платформ на сайте Python, [https://www.python.org/](https://www.python.org/), и могут свободно распространяться. На том же сайте есть также дистрибутивы и ссылки на многие бесплатные сторонние модули, программы и инструменты Python, а также дополнительную документацию.

Интерпретатор Python легко расширять новыми функциями и типами данных, реализованными на C или C++ (или других языках, вызываемых из C). Python также подходит как язык расширений для настраиваемых приложений.

Это руководство неформально знакомит читателя с основными понятиями и возможностями языка и системы Python. Помните, что оно предполагает базовое понимание программирования в целом. Полезно иметь под рукой интерпретатор Python для практики, но все примеры самодостаточны, так что руководство можно читать и офлайн.

Описание стандартных объектов и модулей — в справочнике по встроенным объектам Python и в стандартной библиотеке Python. Более формальное определение языка даёт справочник по языку Python. Чтобы писать расширения на C или C++, прочитайте «Расширение и встраивание интерпретатора Python» и справочное руководство по Python/C API. Есть также несколько книг, подробно освещающих Python.

Это руководство не пытается быть исчерпывающим и охватить каждую возможность или даже каждую часто используемую возможность. Вместо этого оно знакомит со многими наиболее примечательными особенностями Python и даёт хорошее представление о духе и стиле языка. После его прочтения вы сможете читать и писать модули и программы на Python и будете готовы узнавать больше о различных библиотечных модулях, описанных в стандартной библиотеке Python.

Стоит также пройтись по глоссарию.

- Примеры кода, вывод интерпретатора и имена функций оставлены без изменений; переведены только комментарии вне кода и пояснительный текст. Комментарии внутри примеров кода оставлены на английском, как в оригинале.
- В главе 5 и 9 встречается синтаксис распаковки в включениях (`[*x for x in ...]`), а в главе 8 — `except A, B:` без скобок; это новые возможности последних версий Python, они присутствуют в оригинале для 3.15.
- Страницы оригинала, на которые ссылается руководство (глоссарий, справочники), в переводе не включены.
