> [!question] Какой тип перспективы используется во фрагменте росписи Четвёртого стиля из Геркуланума для создания ощущения глубины?
> a) Атмосферная перспектива — чёткие контуры на переднем плане, всё более размытые вглубь композиции.
> b) Одноточечная линейная перспектива со всеми линиями, сходящимися в одной точке.
> c) Обратная перспектива, характерная для византийской иконописи.
> d) В этой росписи не используется вообще никакой намёк на пространственную глубину.
>> [!success]- Answer
>> a) Атмосферная перспектива — чёткие контуры на переднем плане, всё более размытые вглубь композиции.
>> Explanation:
>> Это тот же принцип, что уже встречался в росписи виллы Ливии в Приме-Порте, — передача глубины через изменение чёткости, а не через схождение линий.
>> b), c), d) не соответствуют разбору росписи, проведённому в лекции.
