# Как пользоваться

## А. Меняются только стили → объект breakpoints в `StyleSheet` из Unistyles
Основной путь: на вебе это CSS `@media`, на нативе стили обновляются без ре-рендера.
```tsx
import { StyleSheet } from 'react-native-unistyles'

const styles = StyleSheet.create(theme => ({
  content: {
    paddingHorizontal: { compact: theme.spacing.s16, medium: theme.spacing.s24 },
    flexDirection: { compact: 'column', expanded: 'row' },
    gap: theme.spacing.s16,
  },
}))
```
Значение действует от своего порога и выше: `medium: 24` применяется и на `expanded`/`large`/`extraLarge`, пока не переопределено.

## Б. Меняется JSX / логика → `useBreakpoint`
```tsx
const { isAtLeast } = useBreakpoint()
const isTwoColumns = isAtLeast('expanded')

return isTwoColumns ? <PolicyListWithDetails /> : <PolicyList />
```
Компонент перерисуется при повороте, Split View или ресайзе браузера.

## В. Показать/скрыть блок → `Display` / `Hide` + `mq`
```tsx
import { Display, mq } from 'react-native-unistyles'

<Display mq={mq.only.width('expanded')}>
  <SidePanel />
</Display>
```
> [!warning] Не проверено
> В документации `mq` показан вызов с числами (`mq.only.width(0, 400)`). Поддержку имени breakpoint проверить при реализации.

## Чего не делать
- `if (width > 768)` с магическими числами
- `Platform.isPad`, `isTablet` для раскладки
- `Dimensions.get` вне компонента
- хардкод ширины (`width: 400`)
