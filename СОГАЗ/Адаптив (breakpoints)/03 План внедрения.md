# План внедрения (этап 1: фундамент)

## 1. `@sg/mobile-uikit` (отдельный репозиторий, затем бамп версии)
- Новый файл `theme/tokens/breakpoints.ts`:
  ```ts
  export const breakpoints = {
    compact: 0,
    medium: 600,
    expanded: 840,
    large: 1200,
    extraLarge: 1600,
  } as const
  ```
- `theme/stylesheet.ts`: добавить `breakpoints` в `unistylesConfig`. `nativeBreakpointsMode` оставляем дефолтным (`pixels`, сравнение в dp/pt).
- `theme/themes.ts`: рядом с `UnistylesThemes` объявить тип:
  ```ts
  type AppBreakpoints = typeof breakpoints

  declare module 'react-native-unistyles' {
    interface UnistylesBreakpoints extends AppBreakpoints {}
  }
  ```
- Экспортировать `breakpoints` и `Breakpoint = keyof typeof breakpoints`.
- Опционально, по согласованию с дизайнерами: layout-токены `contentMaxWidth` (например, 600 для форм и 840 для контента). Пока только объявляем.

## 2. Мобильный проект
- `package.json`: новая версия `@sg/mobile-uikit` (без `^`).
- `src/utils/hooks/useBreakpoint.ts`: читает `rt.breakpoint` и `rt.screen` из `useUnistyles()` и возвращает текущий ключ и `isAtLeast(key)`. Имена только позитивные, без `index.ts`.
- `uikit-styles.js` не меняется.

## 3. Правила: дописать в `codeStyle.md` и `AGENTS.md`
- Адаптив решаем по ширине окна (breakpoints UIKit), а не по устройству.
- Значения по breakpoint пишем в `StyleSheet` из `react-native-unistyles`. Условный рендер делаем через `useBreakpoint` или `Display`/`Hide`.
- Mobile-first: от `compact` вверх.
- Без статических `Dimensions.get` и вычислений размеров на уровне модуля.
- Ширину экрана не хардкодим, используем flex и `maxWidth` из токенов.
- 737 RN `StyleSheet` массово не мигрируем, переводим только экраны, которые получают адаптив.

## Проверка
- UIKit: `tsc`, `UnistylesRuntime.breakpoints` содержит 5 ключей.
- Проект: `yarn type-check`, `yarn lint`.
- Веб: ресайз окна через 600/840/1200/1600, в DevTools видны `@media`.
- iOS: iPad mini / 11" / 13", поворот, Split View / окно iPadOS 26.
- Android: эмулятор Tablet и Foldable, поворот телефона.
