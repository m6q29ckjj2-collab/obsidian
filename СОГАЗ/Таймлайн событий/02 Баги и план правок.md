## B. Верстка

| # | Проблема | Где |
|---|---|---|
| B1 | **Шеврон заголовка смещен вниз.** `title` имеет `marginBottom: 16` внутри `titleRow` c `alignItems: 'center'`: высота строки включает margin, и шеврон центруется по «текст + 16», т. е. на ~8 px ниже текста | `BaseAppointmentCard.tsx:338,419` |
| B2 | **Нижние отступы карточки собираются из 6 источников:** `root.paddingBottom` (только при `emptyActions`), `clinicContainerPadding`, `eventMessageContainer.marginBottom` (16, разные в Current и Past), `cancelButtonContainer.marginVertical`, `joinButtonContainer.marginBottom`, `actionsContainer.marginBottom`. Итоговый низ зависит от комбинации. Пример: Past без actions, но с сообщением = 12 + 16 = 28 px, без сообщения = 12 px | `BaseAppointmentCard.tsx`, `CurrentAppointmentCard.tsx`, `PastAppointmentCard.tsx` |
| B3 | **`emptyActions`** считается как `actions?.length === 0 && !shouldDoctorGetInTouchSoon`. Если `actions` когда-то придет `undefined`, отступ не применится | `BaseAppointmentCard.tsx:61` |
| B4 | **`clinicInfoItem: { flex: 1 }`** на `Typography` внутри колонки с `gap: 4` без заданной высоты. На RN-web/Android может давать схлопывание или растягивание строк **(проверить)** | `BaseAppointmentCard.tsx:398` |
| B5 | **Два `TouchableOpacity` вместо одной зоны:** заголовок (дефолтный opacity) и блок врача/клиники (`activeOpacity 0.5`). Тап по карточке подсвечивает только половину | `BaseAppointmentCard.tsx:125,145` |
| B6 | **Аватар без фото:** `doctorAvatarUrl` = `TELEMED_API` + `''`, т. е. валидная непустая строка. Картинка пытается загрузиться по корню API, падает в `onError`, затем подставляется дефолтная (мигание) | `mapTimelineEventToAppointment.ts:276-285`, `BaseAppointmentCard.tsx:101-107` |
| B7 | **Спиннер крутится вместе с шевроном.** `animatedChevronStyle` (поворот на 180°) применяется к обертке, внутри которой при `isLoading` лежит `CircularProgress` | `components/UI/Collapsible.tsx` |
| B8 | **Заголовок группы блокируется на время `isFetching`** (`Pressable disabled`), хотя данные уже могут быть в кеше | `Collapsible.tsx`, `Appointments.tsx` (передает `isFetching`) |
| B9 | **Прыжок высоты при загрузке.** Высота раскрытого контента берется из `onLayout`; когда данные приходят после раскрытия, высота меняется без анимации | `Collapsible.tsx` |
| B10 | **Вложенная типографика:** в `Collapsible` заголовок `Typography H4`, внутрь передается `Typography H6` | `Collapsible.tsx`, `AppointmentsGroupCollapsible.tsx` |
| B11 | **`pointerEvents: 'box-none'` в `StyleSheet`** оверлея загрузки. На RN-web это превращается в невалидный CSS и оверлей перехватывает нажатия (см. заметку из памяти проекта `rnweb-box-none-invalid-css`). Дубль в `CallAppointmentsGroup` | `AppointmentsGroup.tsx`, `CallDoctorAppointmentGroup.tsx` |
| B12 | **«Подбираем время » с пробелом на конце** | `strings.ts:120` |

| # | Проблема | Где |

| C2 | **Нет фолбэка для неизвестного статуса вызова врача.** `configs[type]` вернет `undefined`, и `callDoctorStatusConfig.variant` упадет `TypeError`. Тип статуса в API может расшириться | `CallDoctorAppointment.tsx` |

## Предлагаемый порядок работ

1. **Решить продуктовые вопросы** из [[01 Карточки и шевроны]] (один шеврон, шеврон для past-анализов, цвет).
2. **Шевроны (логика).** Вынести единый расчет «можно ли открыть карточку и где показать шеврон» в один хелпер. Из него же брать `onPressAppointment` для Current и Past. Закрывает A1–A7.
3. **Шевроны и карточка (верстка).** Одна тап-зона (title + doctor block), единый цвет, исправить B1 (вынести `marginBottom` с `title` в контейнер), переделать нижние отступы в один источник (B2, B3).
4. **Группы.** Убрать `FlatList` (D1), починить оверлей (B11), общий `AppointmentsGroup` для вызовов врача (D3). По Collapsible — B7–B10.
5. **Данные.** C1, C2 (минимум: фолбэк для неизвестного статуса), C5–C7.
6. **Разбить файлы** (D2), когда логика устоится.
7. Вызовы врача — оставить как есть до переезда в основной timeline, но закрыть C1–C4.
