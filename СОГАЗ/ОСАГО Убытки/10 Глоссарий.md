# Глоссарий

| Термин | Значение | В коде |
|---|---|---|
| **ОСАГО** | Обязательное страхование гражданской ответственности владельцев ТС | `productType: 'OSAGO'` |
| **Убыток / страховой случай** | Событие (ДТП), по которому пострадавший заявляет выплату | `claim`, `losses` |
| **Черновик** | Серверная заготовка заявления, которая заполняется по шагам | `draft`, `draftId` |
| **Шаг (step)** | Раздел черновика, PATCH-ится отдельно | `steps.stepXxx` |
| **Заявитель** | Пользователь, подающий заявление (потерпевший) | `stepApplicant`, `role: 'victim'` |
| **Виновник / второй участник** | Второй участник ДТП, виновный | `stepSecondParticipant`, «culprit» в аналитике |
| **Пострадавший (здоровье)** | Лицо, которому причинён вред жизни или здоровью | `injured`, `victim: myself\|individual` |
| **ГИБДД / Госавтоинспекция** | Оформление ДТП через полицию. Документ — постановление или определение | `protocolType: 'GIBDD'` |
| **Европротокол** | Оформление ДТП без ГИБДД (бумажный бланк или через Госуслуги) | `protocolType: 'euroProtocol'` |
| **ГУ / Госуслуги / ЕСИА** | Портал госуслуг и система идентификации | `InitialScreenGU`, `ESIA_LOGIN_PATH` |
| **oid** | Идентификатор пользователя в ЕСИА. Есть, если пользователь входил через Госуслуги | `profile.oid`, `stepApplicant.oid` |
| **ПЭП** | Простая электронная подпись (по SMS или подтверждению в приложении) | `signType: 'pep'` |
| **Госключ** | Мобильное приложение для подписания (УНЭП/УКЭП) через Госуслуги | `signType: 'goskey'` |
| **УКЭП** | Усиленная квалифицированная ЭП (для юрлиц). Загружается открепленная подпись `.sig` | `signType: 'ukep'` |
| **Печатная форма** | PDF заявления, генерируется бэком по черновику (по типу ущерба) | `print-form`, `documentumId` |
| **Documentum** | Хранилище документов СОГАЗ (EMC Documentum) | `documentum/{id}` |
| **СТОА** | Станция технического обслуживания автомобилей (ремонт по ОСАГО) | `method: 'repair'`, `stoaName` |
| **Возмещение деньгами** | Выплата на банковские реквизиты | `method: 'bankDetail'` |
| **Почтовый перевод** | Выплата переводом по почтовому адресу | `postalAddress`, `POST_ICON_IMAGE_URL` |
| **Выгодоприобретатель** | Получатель выплаты | `beneficiary` |
| **Самоосмотр** | Фото ТС самим клиентом вместо осмотра экспертом | `stepPhotoDamage`, «self_examination» |
| **ГРЗ** | Государственный регистрационный знак (госномер) | `licensePlate`, `queryType: 'GRZ'` |
| **VIN** | Идентификационный номер ТС (17 символов) | `vinNumber` |
| **СТС / ПТС / ЭПТС** | Свидетельство о регистрации ТС / паспорт ТС / электронный ПТС | `docType: sts\|pts\|epts` |
| **ВУ** | Водительское удостоверение | `DRIVER_LICENSE_UUID` |
| **Код подразделения** | Код органа, выдавшего паспорт (XXX-XXX) | `filialCode`, `departmentCode` |
| **БИК / КПП / к/с / р/с** | Банковские реквизиты | `bik`, `kpp`, `correspondentAccount`, `accountNumber` |
| **е-ОСАГО** | Электронный полис ОСАГО. Такие полисы исключены из выбора ТС пострадавшего | `product !== 'е-ОСАГО'` |
| **Виртуальный полис** | «Полис», собранный на клиенте из `damagedVehicle` для ТС, добавленного вручную | `customPolicy: true`, `id: 'temp-…'` |
| **extDocNumber** | Номер заявления во внешней системе, показывается пользователю | Success screen |
| **Хаб** | [[OsagoLossesResultantScreen]], экран-сводка | — |
| **OutFlow bottom sheet** | Шторка подтверждения выхода из формы | `useOutFlowBottomSheet` |
