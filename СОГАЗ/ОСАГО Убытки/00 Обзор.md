# ОСАГО Убытки — обзор модуля

> [!info] Что это
> Клиентский флоу **«Заявить о страховом случае по ОСАГО»** для потерпевшего. Пользователь собирает заявление по шагам: виновник, данные ДТП, ущерб ТС, имуществу и здоровью, самоосмотр, реквизиты. Затем подписывает его (ПЭП, Госключ или УКЭП) и отправляет в СОГАЗ.
> Всё состояние заявления хранится на бэке в **черновике** (`draft`). Каждый экран PATCH-ит свой `step` в черновике.

- Код: `src/modules/OsagoLosses` (~150 файлов, ~20k строк)
- Стек: `screens/OsagoLossesStack.tsx`, регистрируется в `src/App.tsx` (`{OsagoLossesStack()}`), то есть экраны лежат в корневом стеке, а не во вложенном навигаторе
- API: `osagoLossesSlice/osagoLossesApi.ts` и `slice/osagoLossesApi.ts` (геокодер). Подключены к `mainApiGateway` (RTK Query, `baseUrl = config.BASE_API`)
- Локальный Redux: `slice/osagoLossesStore.tsx`
- Deeplink: `osagoLossesLinkHandler.ts` (`/losses/osago`, `/losses/osago/:draftId`)
- Фичефлаги: `osago_losses`, `osago_losses_property_damage`, `osago_losses_health_damage`

## Флоу в одну строку

```
Вход → Initial (вопросы, черновик) → [GU] → CheckProfile → Resultant (хаб)
  ⇄ SecondParticipant / IncidentData (⇄ AccidentMap) / VehicleDamage (⇄ AddVehicle → AddVehicleForm) / PropertyDamage / HealthDamage
  → [SelfInspection → Vin → Damage] → [BankDetails] → DocumentSign → Success | Failure
```
