# Ветвления, фичефлаги и бизнес-правила

## Фичефлаги (`useFeatures`)

| Флаг | Где проверяется | Эффект |
|---|---|---|
| `osago_losses` | `useOsagoLossesInitialNavigation`, `PolicyDetailsLossesClaimsContent`, `usePolicyDataButtons → kaskoOsago` | Вкл: открывается нативный флоу. Выкл: из SOS/Connect открывается `event.webview`, на полисе кнопки скрыты. **Deeplink-и флаг не проверяют.** |
| `osago_losses_property_damage` | [[OsagoLossesResultantScreen]] | Показ карточки «Ущерб имуществу» |
| `osago_losses_health_damage` | [[OsagoLossesResultantScreen]] | ⚠️ **Фактически не используется.** Из-за ошибки деструктуризации карточка «Вред жизни и здоровью» управляется флагом `osago_losses_property_damage` (`osago_losses_property_damage: osagoLossesHealtDamage`) |

## Правила хаба (Resultant)

- **«Продолжить» активна**, если `stepSecondParticipant && stepAccidentDetails && (stepVehicleDamage || stepPropertyDamage || stepHealthDamage)`.
- Карточка, по которой нет данных, показывает «Недостаточно данных» (`isError`).
- Свитчи «Ущерб имуществу» и «Вред здоровью» начинаются со значений `stepApplicationSelected.*` и меняются **локально**. При «Продолжить» они уходят в Redux `applicationSelectedOverride`. У карточки ТС свитча нет.

## Валидация (valibot, `validation/*`)

Общие правила:
- Адрес обязательно выбирается **из подсказок** (`rawValue` или `house` не пустые): «Выберите адрес из подсказок».
- Даты не могут быть в будущем.
- Год выпуска ТС: от 1900 до текущего года.

| Форма | Ключевые правила |
|---|---|
| CheckProfile | Серия и номер паспорта: 10 цифр (4+6). Код подразделения: 6 цифр. Дата выдачи и «кем выдан» обязательны. ФИО, ДР и тип документа задизейблены и берутся из профиля |
| IncidentData | Дата ≤ сегодня. Время `ЧЧ:ММ`. Участников ≥ 1 (по умолчанию 2). Обстоятельства обязательны. Документы по `protocolType` (развилка 12) |
| SecondParticipant | Полис: 3 буквы + 10 цифр. Адрес из подсказок. Год выпуска в диапазоне |
| VehicleDamage | Схема динамическая: `createVehicleDamageFormSchema(isDriverSameAsOwner, isVehicleNotDriven)`. ИНН юрлица 10 цифр. **Обязательные файлы:** паспорт всегда; ВУ, если ТС управлялось; СТС при `docType = sts`, иначе ПТС; доверенность, если собственник не «я» |
| AddVehicleForm | Дата выдачи СТС/ПТС не раньше года выпуска |
| Bank | БИК 9, ИНН банка 10, КПП 9, счёт 20 цифр |
| SelfInspection | Спереди и сзади ≥ 2 фото каждый. VIN и пробег ≥ 1. Повреждения издалека и вблизи ≥ 2. Место ДТП опционально. Не больше 5 фото и ≤ 10 МБ суммарно на секцию, JPG/JPEG/PDF |
| DocumentSign | Обязательны «данные верны» и «согласие на ПДн». Реклама опциональна. Для УКЭП нужен `.sig` к каждой печатной форме |
| Файлы (`useFileUpload`) | До 5 файлов на поле, до 10 МБ каждый, расширения по полю |

## Автоподстановка данных (откуда что берётся)

| Поле | Источник (по приоритету) |
|---|---|
| Заявитель (CheckProfile) | `GET info/driver` → `GET /api/v1/profile` |
| Контакты заявителя | `info/driver.communicationMethod` → `profile.phone/email` |
| ТС пострадавшего | черновик → полис (`info/transport/{policyId}`) → VIN-поиск → ручной ввод |
| Водитель | черновик → `drivers[0]` полиса → ручной ввод (или «= собственник») |
| Собственник «другое лицо» | `owner` из `info/transport/{policyId}` |
| ТС виновника | `POST info/transport` по госномеру или VIN на blur |
| Пострадавший «я» | черновик → профиль |
| Собственник имущества «я» | профиль (`getPropertyOwnerFromProfile`) |
| Получатель выплаты | список имён: ФИО профиля, собственник ТС, собственник имущества, пострадавший (с учётом выбранных типов ущерба) |
| Реквизиты банка | `GET bank-requisites`; новые по БИК через `suggestions/bank`. **Локально, без сохранения** (FIXME) |
