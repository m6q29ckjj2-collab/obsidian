# Аналитика

Все события отправляются через `AnalyticsService.reportEvent(name, params?)`. Префикс модуля — `yy_osago_`. Схема имени: `yy_osago_{view|click}_{page|button|popup}_…_{page_name}`.

## Пробелы

- Нет событий у: AccidentMap, AddVehicle, AddVehicleForm, HealthDamage, SelfInspectionVin/Damage (view), Success/Failure (view, клики), CheckProfileData, RouterBottomSheet («Продолжить» / «Начать заново»), шторки «Вы виновник», «Полиса нет».
- Нет события на вторичную кнопку «Подписать ПЭП».
- Событие сохранения виновника отправляется даже при ошибке.
